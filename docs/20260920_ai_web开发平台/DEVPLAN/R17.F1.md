# R17.F1 修复:MCP/Skills 管理入口断链(BUG-011)

> 状态:🔄(fixed——代码落地 + tsc 零错误;浏览器复核被并行会话 Vite 中间态阻塞,待其收工后复核置 verified)

## 描述(bug)

用户报告"mcp,skill 的需求怎么没有了"。核实:R17 实现本体齐全(项目设置三子 Tab + 平台 Skills 市场 + 后端接口),但**入口断链**:
1. 项目详情页头菜单「设置」按钮空 onClick(早期占位注释"设置 tab disabled 暂不可用"),点击无响应 → MCP 配置/Skills 管理/模型配置不可达;
2. 侧栏平台管理组无「Skills 市场」项,/admin/skills 孤立。

## 实现要点

1. `frontend/src/pages/projects/ProjectDetail.tsx`:actionMenu「设置」按钮 → `onClick={() => { setActionMenu(false); navigate('?tab=settings') }}`(与 tabs 导航方式一致;删除过期占位注释)
2. `frontend/src/components/layout/MainLayout.tsx`:NAV_ADMIN 追加 `{ to: '/admin/skills', label: 'Skills 市场', icon: Blocks }`(置于平台管理组;侧栏保持单行 icon+label,用户已拍板)

## 测试验证逻辑(修复后回归)

1. `npx tsc --noEmit` 零错误
2. Playwright(超管):
   - 侧栏平台管理组出现「Skills 市场」,点击进入 /admin/skills 页面正常渲染(Skills 市场 h1 + 新建 Skill 按钮)
   - 项目设置入口:静态核对 navigate('?tab=settings') 接线(dev 库无项目且 GitLab token 401 无法建项目,运行时受限如实留痕)
3. 功能零回归:tabs 点击行为不变;admin 路由守卫不变
