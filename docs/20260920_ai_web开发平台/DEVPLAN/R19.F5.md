## 描述(即 bug)

用户打开审计日志页,接口 `/api/admin/audit-logs` 返回空(共 0 条),页面显示"暂无符合条件的日志"。实证后端正常:同接口裸调(无筛选参数)返回今日 63+ 条事件。

**复现步骤**:超管打开 `/admin/audit-logs`(默认时间筛选"最近 7 天")→ 页面发 `GET /api/admin/audit-logs?start_time={toISOString UTC 串}&end_time={...}` → `code 0 / total 0`。
**期望**:最近 7 天有 63+ 条事件,页面列表有数据。
**根因(复放矩阵实证)**:前端用 `toISOString()` 发 **UTC** 串(end_time 落后本地 8h),而 `audit_logs.created_at` 是 MySQL DATETIME 存**本地(UTC+8)裸墙钟**,字面比较 → 全部事件落在 [start,end] 之外 → total 0。仅 end_time=UTC → 0 条;本地裸串/+8h → 65 条。

## 实现要点(根因 + 修复方案)

**主修(前端 AuditLogsPage.tsx 为核心,适配后端契约 + 用户指令:默认时区 = GMT+8)**:
1. 时间筛选 state 存 **GMT+8 裸时间串**(`YYYY-MM-DDTHH:mm`),由显式 Asia/Shanghai 格式化产生(**不得**用 `toISOString()` 的 UTC,也**不得**依赖浏览器本地时区的方法如 `toLocaleString()` 无参形式)——约 4 处 `toISOString()` 全部替换;input 直绑同源裸串(消除 8h 显示偏移)
2. 时间列显示:直接渲染后端返回的 `created_at` 裸字符串(GMT+8 墙钟,无 Z 后缀,**禁止**经 `new Date()` 再格式化——那会被浏览器时区重解释);若必须格式化,用固定 +08:00 偏移
3. 清空时间输入不再经 `new Date('')` 抛 RangeError
4. **P2 同文件补齐**:① isError/错误态分支(403/19002/5xx 不再静默渲染空表;401/403 给"请重新登录"提示);② `start > end` 时查询禁用(R19.F2 分片规格原文,实现缺失)

**后端固化(用户指令,1 文件小改)**:`app/database.py` 引擎建立时给 asyncmy 连接加会话级 `time_zone='+08:00'`(init_command 或等价机制,以该 SQLAlchemy/asyncmy 版本实际支持为准)——`func.now()` 写入的墙钟从"碰巧是 +08:00"变为**契约保证**;与存量数据(已实证 +08:00 墙钟)一致,零数据迁移。改后需重启 uvicorn 生效。

**波及排查(同根因合并原则)**:grep 前端其余 `toISOString()` 用作查询参数的调用点(重点 R22.F2 重写的四维管理页,同 audit-logs 范式),命中同缺陷一并修并留痕;无命中则报告"0 处"收口。

## 测试验证逻辑(修复后按此回归)

1. **红测(先失败)**:headless 浏览器(超管登录态)打开 `/admin/audit-logs` → 断言列表行数 > 0——修复前必 0(复现 BUG-039);留 Red 证据
2. **绿**:同断言通过,行数 ≥ 63;时间列显示 GMT+8 墙钟(与 API `created_at` 一致,无 8h 偏移)
3. **时区钉死判据(用户指令核心)**:Playwright context 强制 `timezoneId: 'America/New_York'`(非 GMT+8 浏览器)打开同页 → 行数仍 ≥ 63、筛选参数仍是 GMT+8 串;时间列显示值与 GMT+8 浏览器下完全一致
4. **参数级复放**:页面实际发出的请求参数用 curl 复放 → total ≥ 63(不再 0)
5. **边界**:清空时间输入不再报错、可重查;start>end 时查询按钮禁用;伪造 401(token 失效)显示错误态而非静默空表
6. **后端固化验证**:重启 uvicorn 后新建一条审计事件(如登录)→ DB `created_at` 仍为 +08:00 墙钟;全量 backend pytest 无回退(引擎改动波及 conftest 同工厂)
7. **门禁**:`npx tsc --noEmit` 零错误 + `npx vite build` 通过
8. **留痕**:静态核对写 `.scratch/R19.F5/ui-check.md`
