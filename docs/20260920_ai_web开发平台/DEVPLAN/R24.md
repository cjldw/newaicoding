## 页面结构说明

- **页面区块结构**(左 → 右):
  1. **左侧分类导航**(垂直,复用 SettingsLayout 形态):4 项——GitLab 集成 / 域名配置 / 全局参数 / 模型默认配置;当前项高亮
  2. **右侧内容区**:单卡片,仅渲染当前分组表单
- **本需求点改动范围**:整页布局重排(改布局);三组既有表单控件与保存/测试连接逻辑平移不改交互;新增第 4 组(R23 内容)
- **涉及区块细节**:内容卡片用 `.card`(p-6、rounded-lg 0.75rem、border-border、shadow-sm);**卡片 max-width 672px**(max-w-2xl),不再撑满整行
- **表格列级规格**:无(无表格)
- **表单布局**:每分组一行一列,label 上置;GitLab 集成 4 字段 + 测试连接按钮;域名配置 2 字段;全局参数 3 字段;模型默认配置 3 字段(R23)

## 路由与入口

- 路由:`/admin/settings`(现有,不变)
- 菜单/入口:左侧导航 → 平台管理 → 平台设置(仅超管可见,RequireRole 守卫)
- 返回:浏览器/侧栏切换,无页内返回动作
- 前置条件:superadmin 登录态

## 页面交互流程

- 进入:侧栏点击 → 默认渲染 GitLab 集成分组(加载 GET 全量配置,现状接口)
- 切换分组:点左导航项 → 右侧切换表单;**未保存修改直接丢弃**(无确认,V1 已确认口径)
- 保存:当前分组保存按钮 → PUT(分组对应键)→ 成功 toast"保存成功";失败 → 表单上方错误 banner(保留输入)
- 测试连接:GitLab 分组按钮 → POST test-connection → 成功/失败样式按 R2.F4 修复后的口径(ok=true 判定),**回归不破坏**

## 控件联动

| 触发控件 | 事件 | 响应行为 |
|---|---|---|
| 左导航项 | click | active 态切换 + 右侧表单替换(卸载其余分组,丢弃未保存值) |
| 保存按钮(每分组独立) | click | 仅提交本分组键集合(见下);禁用至响应返回(防重) |
| GitLab-测试连接 | click | 现有行为不变 |
| 模型默认-保存 | 含 llm_* 键 | 三键齐备校验 + 2008 连通测试(R23 契约) |

- 各分组提交键集合:GitLab=gitlab_url/gitlab_bot_token/gitlab_bot_group_id;域名=preview_base_domain/deploy_base_domain;全局参数=max_containers_total/kb_max_pages_per_kb/kb_max_file_mb;模型默认=llm_base_url/llm_api_key/llm_model

## 设计规范

**① 设计 Token**:同 R2(zinc 色板 globals.css:--color-* 全套)

**② 布局规则**:

| 区块 | 布局方式 | 对齐 | 区块内间距 | 区块间外边距 | 背景 | 约束方式 |
|---|---|---|---|---|---|---|
| 页面容器 | flex row | 顶部对齐 | gap 16px | 0 | bg-page | 导航定宽 stretch 高 |
| 左导航 | flex column | 左对齐 | item padding 8px 12px | item 间 4px | bg-surface(与 SettingsLayout 同构) | width 200px 固定,hug 高 |
| 内容卡片 | block | 左对齐 | .card p-6 | - | bg-surface border-border rounded-lg shadow-sm | **max-width 672px**,hug 高 |
| 表单行 | flex column | 左对齐 | 行间 12px | - | - | label+input 全宽(fill) |

**③ 组件规范**:Input/Button/Badge 状态表同 R2;导航 item:

| 状态 | 背景 | 文字 | 边框 |
|---|---|---|---|
| 默认 | transparent | text-main | 无 |
| hover | bg-surface-strong | text-main | 无 |
| 选中(active) | bg-surface-strong | text-main(font-weight 600) | 左侧 2px primary 竖线 |
| 禁用 | 不适用(4 项恒可用) | - | - |

**④ 关键细节兜底**:打码回显值只读展示(input readOnly);导航在 1280px 以下不折叠(V1 后台固定桌面)
**⑤ 效果层**:无效果(无渐变/阴影动画;卡片 shadow-sm 现值)

**动效**:无(仅 Tailwind transition-all 默认)
