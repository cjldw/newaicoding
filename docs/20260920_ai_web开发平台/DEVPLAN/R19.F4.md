# R19.F4 修复:用户管理页搜索筛选与表格零间距(BUG-UI-006)

> 状态:⬜

## 描述(bug)

BUG-UI-006(用户报告):用户管理页(/admin/users)搜索组件和 table 有重叠。

**运行时实测(2026-09-22 Playwright getBoundingClientRect)**:筛选栏(`flex items-center gap-3`,bottom=163)与下方表格 `.card`(top=163)**间距 0.0px**——筛选控件与卡片边框完全相贴,用户观感即"重叠"。

**连带 vp 偏差(同区块,顺带对齐)**:
- 页头 `<h1>用户管理</h1>` 缺 vp 的图标与副标题(vp L197:`${ic('users',18)} 用户管理` + `.sub` 说明)
- 「邀请新用户」按钮为 `btn`(灰)而非 vp 的 `btn btn-pri`(主色,vp L198)
- 注:筛选栏本身是实现层新增的功能(vp 原型此页无筛选),**功能保留**,只修布局归属

## 实现要点

`frontend/src/pages/admin/UserManagementPage.tsx`:

1. **筛选栏归位**:`.fbar` 是 vp 语言中"卡片内顶部筛选条"(globals.css L358:`padding:12px 16px; border-bottom:1px solid var(--border)`),将筛选控件(状态 Select + 搜索 Input)移入表格 `.card` 内、`.scrollx` 之前,作为 `.fbar` 条:
   ```
   <div className="card">
     <div className="fbar">…状态筛选 + 搜索框…</div>
     <div className="scrollx"><Table className="tbl">…</Table></div>
     <div className="card-foot">…分页(既有)…</div>
   </div>
   ```
   间距由 `.fbar` 的 padding 与 border-bottom 天然解决,不再与卡片相贴
2. **页头对齐 vp**:`<h1><Users size={18} /> 用户管理</h1>` + `<div className="sub">平台级账号管理(仅超管)· 禁用即全失效</div>`(文案照抄 vp L197 的 sub),结构与 /projects 页头同构(标题+sub 在左 div,.acts 在右)
3. **邀请按钮**:`className="btn"` → `className="btn btn-pri"`

**约束**:筛选/搜索/分页功能逻辑一行不动,只动容器层级与类名;表格列与数据渲染不动。
