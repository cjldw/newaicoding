# R26.F3:BUG-050 终端读循环 SocketIO 兼容(容器形态 runner 秒崩零输出)

> 状态:✅ 完成(2026-09-24 rd-fix 第 26 轮;verified 迁移 ISSUES.md)
> 模块:M5(runner/terminal_manager.py `_read_loop`;波及 R9 任务终端与 R26 Runner 终端的一切 Linux 容器形态)
> 关联:BUG-050;R31.F3 容器形态验证中发现

## 描述与根因

- **复现**:容器形态 runner(rd49-docker)开 R26 终端 → 读循环秒崩,浏览器零输出;容器日志 `AttributeError: 'SocketIO' object has no attribute 'recv'`(terminal_manager.py `_read_loop`)
- **根因**:`_read_loop` 硬编码 `session.sock.recv(4096)`;docker `exec_start(socket=True)` 在标准 Linux/Docker Desktop 返回 **SocketIO**(file-like,只有 `.read()`),Windows 原生 NpipeSocket 才有 `.recv()`——历史仅在 Windows 裸跑验证过,故从未暴露(R26 判据 4/8/11「真实 pty 场景待 rd-test」之债;Linux 生产节点同样会踩)

## 修复

`_read_loop` 探测式读法:`hasattr(sock,"recv") ? recv : read`(与 BUG-031 写侧 sendall 探测同思路);单点改动,pty 缓冲/回调逻辑零变化。
