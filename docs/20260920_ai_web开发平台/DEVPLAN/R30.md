## PRD 引用

### 边界定义(摘录)

- **做什么**:① 亮色/暗色切换(顶部栏右侧太阳/月亮图标按钮);② 默认跟随系统(`prefers-color-scheme` 检测);③ localStorage 持久化存储 `theme` 字段;④ CSS 变量切换(`[data-theme="dark"]` 覆盖 `:root`);⑤ 核心布局覆盖(侧栏、顶栏、卡片、表格、表单、按钮等基础组件)
- **不做什么**:不做多主题(仅亮/暗两套);不做自定义配色;不做 Monaco 编辑器主题切换(保持 `vs-dark`);不做终端主题切换(保持 `--term-bg: #0e1116`);不做 SSR/内联脚本优化防 FOUC;语义色不随主题变(红/绿/蓝/琥珀色徽章保持固定色值)

### 异常与边界场景(摘录 + 挖掘)

- 浏览器不支持 `prefers-color-scheme`:默认亮色
- localStorage 被禁用:每次访问跟随系统(V1 接受)
- 页面加载闪烁(FOUC):接受短暂闪烁(<100ms)
- 硬编码颜色:部分 inline style 或第三方组件可能不跟随主题,V1 允许存在
- (挖掘·引用)Monaco 编辑器:保持 `vs-dark` 不随主题切换(行业惯例)
- (挖掘·引用)终端:保持 `--term-bg: #0e1116` 不随主题切换

### 验收标准(摘录)

1. 亮色/暗色切换即时生效,无页面刷新
2. 刷新后保持用户选择的主题
3. 首次访问正确跟随系统主题
4. 核心布局组件(侧栏/顶栏/卡片/表格/表单)颜色正确切换
5. Monaco 编辑器和终端保持暗色不变

### 2. 主题切换 Hook

```typescript
// frontend/src/hooks/useTheme.ts
import { useEffect, useState } from 'react'

type Theme = 'light' | 'dark'

export function useTheme() {
  const [theme, setTheme] = useState<Theme>(() => {
    // 首次:检测系统
    if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
      return 'dark'
    }
    return 'light'
  })

  useEffect(() => {
    // 读取 localStorage
    const saved = localStorage.getItem('theme')
    if (saved === 'light' || saved === 'dark') {
      setTheme(saved)
    }
  }, [])

  useEffect(() => {
    // 应用到 DOM
    document.documentElement.setAttribute('data-theme', theme)
    localStorage.setItem('theme', theme)
  }, [theme])

  const toggle = () => {
    setTheme(prev => prev === 'light' ? 'dark' : 'light')
  }

  return { theme, toggle }
}
```

### 4. 系统主题监听

```typescript
useEffect(() => {
  const media = window.matchMedia('(prefers-color-scheme: dark)')
  const handler = (e: MediaQueryListEvent) => {
    // 仅当 localStorage 无存储值时跟随系统
    if (!localStorage.getItem('theme')) {
      setTheme(e.matches ? 'dark' : 'light')
    }
  }
  media.addEventListener('change', handler)
  return () => media.removeEventListener('change', handler)
}, [])
```
