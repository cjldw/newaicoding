# R32.F6:修复 BUG-057/058 任务事件推送链(流式对话前端不可达)

> 状态:✅(verified 2026-09-27,用户复验通过,迁移 ISSUES.md)
> 模块:M5(runner+后端;R32.F3 流式特性延续)
> 关联:BUG-057(注册崩溃)、BUG-058(粒度)

## BUG-057 根因(一手证据)

`TaskEventRegistry.connect` 把 conn(dict)塞进 set → `TypeError: unhashable type: 'dict'`
→ events WS 端点 accept 后崩断(无关闭帧)→ 注册表永远空 → broadcast conns=0 →
chat_delta/chat_done/tool_call/file_changed **全部任务事件推送自上线起对前端不可达**。

## BUG-058 根因与终极发现

- runner cmd 未加 `--include-partial-messages`(CLI 默认按 turn 整块)
- **整段呈现的终极根因(环境限制)**:容器内直连上游网关 SSE 实测 2928 行 span=0.00s
  (59.10s 全量同瞬间到达)——网关攒齐完整响应才返回,不支持流式

## 修复

1. registry 存 websocket 本体(dict[str, list]),对外契约不变
2. runner cmd 加 `--include-partial-messages`;平台 `_stream_event_to_chat` 增
   stream_event/content_block_delta/text_delta 映射(assistant 整块回退保留)

## 验证

- pytest 5/5 + runner 43/43
- 真机探针:14 帧(11 chat_delta + chat_done + ping),增量可达实证
- 整段呈现归网关;网关开启流式后零改动变逐字
