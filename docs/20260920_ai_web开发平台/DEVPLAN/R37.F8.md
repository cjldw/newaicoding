# R37.F8:修复 BUG-082 打磨完成静默跳过 commit(创建者无 token 时回退 bot token + 显式报错)

- **状态**:⬜
- **关联 BUG**:BUG-082(用户报障「生成的prd没有提交仓库中」)
- **根因**:`task_service.finish_task` 只取创建者个人 token,创建者未绑定时 `creator_token=""` → `if runner_conn is not None and creator_token:` 整段 commit/push 静默跳过;任务照常 done,前端 toast 谎称「PRD 已推送」(实锤:需求 0d227c83 创建者 2845fe31 has_token=0,两次 finish 需求分支零 commit)
- **修复方案**:
  1. 提交凭据链改为 `creator_token or bot_token`(bot 经 `platform_settings_service.get_gitlab_bot_config` 取;需求分支即 bot 所建,天然有推送权)
  2. 两者皆无 → `BizError` 显式报错(文案指导绑定 token / 配置平台 GitLab),**不再静默 done**
  3. bot 配置缺失的 2001 文案不友好 → 捕获后重抛带行动指引的文案
- **涉及文件**:`backend/app/services/task_service.py`(finish_task)
- **测试验证逻辑**(复现步骤 + 期望):
  - 用例 A:创建者无 token + 平台已配 bot → finish 调 git_commit 时收到的 token=bot_token,任务 done
  - 用例 B:创建者无 token + bot 未配置(get_gitlab_bot_config 抛 2001)→ finish 报 BizError(文案含「绑定」指引),任务状态**不**变 done
  - 用例 C:创建者有 token → 行为不变(token=creator_token)
  - 回归:test_bug073_container_leak.py::TestFinishTaskAllContainers、test_prd_sync.py::test_finish_task_syncs_prd_for_requirement_only
- **完成判据**:新用例 Red→Green;触碰面 pytest 全绿;后端生效(finish 真机路径由用户下次打磨复验)
