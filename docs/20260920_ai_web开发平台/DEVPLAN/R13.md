## PRD 引用

### 边界定义

- **做什么**:项目级 url+key+model,多组配置(主/备),连接性测试,会话级覆盖
- **不做什么**:平台统一计费/key 池/模型路由

### 交互规则

| 场景/条件 | 行为/规则 | 结果/去向 |
|---|---|---|
| 保存 | `GET {base_url}/models` 连通性测试,失败拒绝 | 提示错误 |
| 任务执行 | 默认 default 配置;启动任务时可临时切换(会话级) | 当次生效 |
| key 展示 | 前 4 + 后 4,中间 *** | |
| 删 default | 拒绝,先指定新 default | |
| **SDK 模式** | 平台后端用配置调 LLM(主路径) | |
| **CLI 模式** | 平台把配置注入容器 env(`ANTHROPIC_BASE_URL` / `ANTHROPIC_API_KEY` 或对应变量) | Claude CLI 用 |

### 异常与边界场景

- 容器内 env 注入的 key **仅容器内存**,不落容器镜像/日志
- 未配置时,任务/AI 辅助入口禁用并引导

### 验收标准

1. 至少能配置 Claude/OpenAI/DeepSeek 任意兼容 endpoint 跑通任务
2. key 不明文出现在接口/日志/前端
3. SDK 与 CLI 两种模式都能用同一组配置

### 接口契约

**接口契约** 总览——**响应结构**统一外层 `{"code": 0, "data": ..., "message": "ok"}`(错误时 `code` 为业务错误码、`message` 为提示文案);字段级结构以下方各接口小节的请求/响应示例为准:

| 接口范围 | 响应结构约定 |
|---|---|
| 本需求点全部接口(下方小节逐一列出) | 统一外层 `{code, data, message}`;分页接口 `data` 含 `{items, total}` |

#### 1. 模型配置列表

- **路径**:`GET /api/projects/{project_id}/model-configs`
- **鉴权**:JWT(项目成员)
- **响应**:
  ```json
  {
    "code": 0,
    "data": {
      "items": [
        {
          "config_id": "uuid",
          "name": "string",
          "base_url": "string",
          "api_key_masked": "sk-***-xyz",
          "model": "claude-sonnet-5",
          "is_default": true,
          "enabled": true,
          "created_by": {
            "user_id": "uuid",
            "username": "string"
          },
          "created_at": "datetime"
        }
      ]
    },
    "message": "ok"
  }
  ```

#### 2. 创建模型配置

- **路径**:`POST /api/projects/{project_id}/model-configs`
- **鉴权**:JWT(owner)
- **请求**:
  ```json
  {
    "name": "string(64)",
    "base_url": "string(http/https)",
    "api_key": "string",
    "model": "string(64)",
    "is_default": false,
    "enabled": true
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": { /* 同列表项 */ },
    "message": "创建成功"
  }
  ```
- **错误码**:
  - `13001`: base_url 不通(连通性测试失败)
  - `13002`: 同项目下配置名重复
  - `13003`: 同项目已有 default 配置(is_default=true 时)

#### 3. 更新模型配置

- **路径**:`PATCH /api/projects/{project_id}/model-configs/{config_id}`
- **鉴权**:JWT(owner)
- **请求**:
  ```json
  {
    "name": "string(可选)",
    "base_url": "string(可选)",
    "api_key": "string(可选,更新时重新加密)",
    "model": "string(可选)",
    "is_default": "bool(可选)",
    "enabled": "bool(可选)"
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": { /* 同列表项 */ },
    "message": "更新成功"
  }
  ```

#### 4. 删除模型配置

- **路径**:`DELETE /api/projects/{project_id}/model-configs/{config_id}`
- **鉴权**:JWT(owner)
- **响应**:
  ```json
  {
    "code": 0,
    "message": "删除成功"
  }
  ```
- **错误码**:
  - `13004`: 不可删除 default 配置(需先指定新 default)

#### 5. 连通性测试

- **路径**:`POST /api/projects/{project_id}/model-configs/test`
- **鉴权**:JWT(owner)
- **请求**:
  ```json
  {
    "base_url": "string",
    "api_key": "string",
    "model": "string"
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": {
      "success": true,
      "latency_ms": 123
    },
    "message": "连接成功"
  }
  ```
- **错误码**:
  - `13001`: 连接失败(超时/401/404)

### 服务端行为规格

#### 连通性测试

1. 调 `GET {base_url}/models`(OpenAI 兼容协议)
2. 请求头:`Authorization: Bearer {api_key}`
3. 超时:10s
4. 200 → 成功,返回延迟
5. 401 → 返回 `13001`(api_key 无效)
6. 404 → 返回 `13001`(base_url 错误)
7. 超时 → 返回 `13001`(连接超时)

#### AES-GCM 加密

- 加密字段:`api_key_encrypted`
- 密钥:环境变量 `PLATFORM_SECRET_KEY`(同 R1)
- 格式:`base64(nonce + ciphertext + tag)`

#### key 打码

- 接口返回时,`api_key` 字段打码:前 4 位 + `***` + 后 4 位
- 例:`sk-1234567890abcdef` → `sk-1***cdef`

#### SDK 模式(任务执行时)

1. 任务创建时,平台读 `model_configs` 表的 `is_default=true` 配置(或用户指定的会话级配置)
2. 解密 `api_key_encrypted`
3. 用 `claude-agent-sdk` 调 LLM:
   ```python
   from claude_agent_sdk import ClaudeSDKClient

   client = ClaudeSDKClient(
       base_url=config.base_url,
       api_key=decrypted_api_key,
       model=config.model
   )
   ```

#### CLI 模式(容器内)

1. 任务创建时,平台把配置注入容器环境变量:
   - `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL`(通用)
   - `ANTHROPIC_BASE_URL` / `ANTHROPIC_API_KEY`(Claude CLI 兼容)
2. 容器内 Claude CLI 自动读这些环境变量

### 页面结构说明

#### 模型配置 Tab `/projects/{project_id}/settings/models`

- **区块结构**:
  1. **操作栏**:右侧"新建配置"按钮(primary)
  2. **配置列表**(Table):
     - 列:配置名(带 default 徽章)/ base_url / model / api_key(打码)/ 状态徽章(enabled/disabled)/ 创建人 / 创建时间 / 操作(编辑/删除/测试)
     - default 行的"删除"按钮禁用
  3. **新建/编辑配置对话框**:
     - 配置名输入框(label="配置名",placeholder="如:主用 Claude")
     - base_url 输入框(label="Base URL",placeholder="https://api.anthropic.com")
     - api_key 输入框(label="API Key",type=password,placeholder="sk-xxx")
     - model 输入框(label="模型",placeholder="claude-sonnet-5")
     - is_default 复选框(label="设为默认")
     - enabled 复选框(label="启用",默认勾选)
     - "测试连接"按钮(secondary)
     - "取消" + "保存"按钮
  4. **删除确认对话框**:
     - 提示:"确定删除配置 {name} 吗?"
     - "取消" + "确定"按钮

### 页面交互流程

#### 创建配置流程

1. 用户点"新建配置" → 打开对话框
2. 填表 → 点"测试连接"(可选)→ 调 `POST /test` → 显示成功/失败
3. 点"保存" → 前端校验(zod schema)→ 调 `POST /api/projects/{pid}/model-configs`
4. 成功 → 关闭对话框 → 刷新列表
5. 失败 → 显示错误提示

#### 编辑配置流程

1. 用户在列表点"编辑"
2. 打开对话框 → 显示当前配置(api_key 显示打码)
3. 修改字段 → 点"保存"
4. 调 `PATCH /api/projects/{pid}/model-configs/{config_id}`
5. 成功 → 关闭对话框 → 刷新列表

#### 删除配置流程

1. 用户在列表点"删除"(非 default)
2. 弹出确认对话框
3. 点"确定" → 调 `DELETE`
4. 成功 → 刷新列表
