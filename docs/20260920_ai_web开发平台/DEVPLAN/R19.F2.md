# R19.F2 修复:超管管理块前端补全——用户管理/审计日志页 + 路由守卫 + 外壳(BUG-002/003/004)

## 状态:⬜

## 描述(bug)

三个同根因 bug(R19 前端批次遗漏,合并一个修复点):

- **BUG-002**:`/admin/users`、`/admin/audit-logs` 路由未注册;`UserManagementPage` / `AuditLogsPage` 组件不存在(R19 决策留痕称"并入 R21/R22 前端批次",实际该批次未包含)。后端接口已就绪(用户列表/禁用启用/邀请/审计查询,Guard 19002)。
- **BUG-003**:admin 路由无 `meta.role=superadmin` 守卫,普通用户可直达页面(后续 API 才 403)。规格:非超管访问 `/admin/*` 重定向 `/`(Dashboard)。
- **BUG-004**:`/admin/platform-settings`、`/admin/runners` 为顶层路由,游离在 MainLayout 外壳之外——进入后无侧边栏/顶栏,与"平台管理"导航分组的使用动线断裂。

> 已接受偏差:R19 文件结构中的 `AdminNav.tsx` 不单独建文件,导航项维持 MainLayout 内联(行为符合规格,BUGS.md 有记录)。

## 实现要点(根因 + 修复方案)

### BUG-002:两个页面 + api client + 路由注册
1. 新建 `frontend/src/api/admin.ts`:用户列表(`GET /api/admin/users`,status/搜索/分页)、禁用启用(`PATCH /api/admin/users/{id}/status`)、平台邀请(列表/生成/撤销)、审计查询(`GET /api/admin/audit-logs`,时间/用户/操作类型/分页)——以 backend 实际路由为准(先读 `backend/app/api/admin/` 确认路径与字段)
2. 新建 `frontend/src/pages/admin/UserManagementPage.tsx`,按 R19 母分片页面结构:
   - 筛选栏:状态下拉(全部/正常/已禁用)+ 搜索框(手机号/昵称,防抖 300ms)
   - 工具栏:"邀请新用户"按钮(primary)
   - 用户列表 Table:手机号(打码)/ 昵称+头像 / 角色徽章(superadmin=primary/user=outline)/ 状态徽章(active=success/disabled=danger)/ GitLab 绑定(已绑定✓/未绑定—)/ 注册时间 / 操作(禁用|启用 / 邀请记录)
   - 分页器 20/页;空态"暂无用户"
   - 邀请对话框:手机号(选填)+ 生成邀请 → 一次性 token(mono 字体)+ 复制按钮(2s 后"已复制"复原)+ 7 天有效期提示;关闭不撤销
   - 禁用确认对话框:"确定禁用用户 {nickname} 吗?其现有登录将立即失效,进行中的任务将被取消";成功 toast"已禁用,取消 N 个进行中任务";19001 → toast"最后一个超级管理员不可禁用";目标超管且仅 1 超管时按钮禁用(前端提示,服务端兜底)
3. 新建 `frontend/src/pages/admin/AuditLogsPage.tsx`:
   - 筛选栏:时间范围(默认最近 7 天;start>end 时查询禁用)+ 用户下拉(可搜索)+ 操作类型下拉 + 查询按钮
   - 日志 Table:时间 / 操作者(昵称 + superadmin 徽章若 operator_role=superadmin)/ 操作类型 / 项目 / 目标 / 详情(JSON 摘要,Tooltip 悬浮全量,列宽 320px 溢出省略)/ IP
   - 分页 20/页,created_at 倒序;空态"暂无符合条件的日志"
4. router 注册 `/admin/users`、`/admin/audit-logs`

### BUG-003:角色守卫
- 路由级守卫:`/admin/*` 校验 `authStore.user.role === 'superadmin'`,非超管 `<Navigate to="/" />`;user 未恢复时等待 init(避免误判踢回)

### BUG-004:外壳归位
- 全部 `/admin/*` 路由(platform-settings / runners / users / audit-logs)挂到 MainLayout 子路由,复用既有外壳与「平台管理」导航分组

### 约束
- 组件复用既有封装(Table/Dialog/Select/Badge/Table 分页、`bgd`/`bdg`/`tbl` 等 globals.css 组件类),不引新依赖;DatePicker 若无既有封装用两个 date input 简化实现(行为等价)
- 文案严格按 R19 文案清单;403 全局拦截 toast"无权限执行此操作"(若全局 axios 拦截已有 403 处理则复用)
- 遵循代码纪律:复杂逻辑留注释;if/else 早 return
