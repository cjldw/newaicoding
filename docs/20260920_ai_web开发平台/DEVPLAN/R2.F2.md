BUG-UI-004(用户指令):内容区各页大标题按 vp/index.html 页头样式——icon + 标题,换行,下方说明文字。用户补充:工作台、项目页也要加(此两点超出 vp 原样,vp 中这两页 h1 无 icon——用户偏好优先,留痕)。

**vp 事实(照抄源)**:
- vp pageManage L1691:`<h1>${ic(conf.icn,18)} ${conf.title}</h1><div class="sub">${conf.desc}</div>`
- vp Runner L1569 / 用户 L1775 / 审计 L1809 / 知识条目 L1544 均同构
- vp Dashboard L1648 / 项目 L881:h1 无 icon、有 sub
