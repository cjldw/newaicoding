## PRD 引用(R32 增量6,Q58–Q62 已确认)

### 边界定义(摘录)

- **做什么**:① tag 模型=固定枚举 `requirement(需求)/dev(开发)/test(测试)`,一个 runner 0~3 个;② **调度匹配**(worker 域):候选=online+role=worker+容量未满+(`tags 含任务类型` **或** `tags 为空`)→ 最少负载(既有算法不变,仅候选过滤加一层);无匹配 → 8003 排队(文案不变,调度日志细分"等待 {类型} Runner");③ **release 不参与 tag**(仍 role=deploy);④ **编辑**:除 role/token 外全字段可改——名称(16005 唯一)/最大容器数(调小允许,存量容器不动)/tags;deploy 行加公网 IP;新增 `runner.update` 审计(before/after tags);⑤ 新建(远程+R31 快速创建)加 tag 多选(默认全不勾=兜底);⑥ 列表新增「任务类型」列 chips(空显示「通用」)
- **不做什么**:不做自由标签(GPU/资源标签)与「任务类型→tag」映射配置;**role/token/is_local 不可编辑**(换角色=删了重建);无匹配 runner 时前端排队文案不变;不做调度权重
- **关键语义**:未打 tag 的 runner=兜底接**所有** worker 任务(存量 runner 行为零变化);打了 tag 即**专属**(只接同名类型,不互兜底)

### 异常与边界场景(摘录 + 挖掘)

- 某类型专属 runner 全部离线:任务 8003 排队(既有);调度日志细分等待类型
- 编辑名称与他 runner 冲突 → 16005;名称未变 → 跳过唯一校验(避免自撞)(挖掘)
- tags 含枚举外值/重复 → 16008 拒绝(挖掘;PRD 验收写"400"系口径笔误,按仓内统一响应 HTTP 200+code,留痕)
- deploy 行提交非空 tags → 16008 "deploy Runner 不参与任务类型标签"(挖掘·决策 A1:显式拒绝优于静默忽略)
- 编辑 disabled runner → 允许(禁用只挡调度,元数据无碍)(挖掘·决策 A3)
- 编辑与调度并发:调度实时查库,单行 UPDATE 原子,以查询瞬间快照为准(挖掘·决策 A5)
- max_containers 调小且当前容器超新值 → 允许,存量容器跑完为止,新调度按新值卡容量(挖掘·决策 A6)
- 本机 runner(is_local)编辑:tag/名称/最大容器数可改,不影响进程与启停;spawn 的 RUNNER_ROLE 恒 worker,tag 只影响平台侧调度匹配(挖掘)
- runner 被删后再编辑 → 404

### 验收标准(摘录)

6 条(PRD R32):tag 匹配分配 / 专属离线排队且专属不互兜底 / 编辑+审计 / 快建带 tag / 存量兜底回归 / 403+非法 tags 拒绝

### 接口:编辑 Runner
- 类型:**新建** `PATCH /api/admin/runners/{runner_id}`
- 请求体(全部可选,未传=不改动):`{ name?: string(1-64), max_containers?: int(1-100), tags?: list[str], public_ip?: string }`
- 校验:runner 存在(404);name 变更且冲突 → 16005"Runner 名称已存在,请更换";tags 非法/含未知值 → 16008"任务类型标签非法:{值}";role=deploy 且 tags 非空 → 16008"deploy Runner 不参与任务类型标签";deploy 行 public_ip 置空 → 2007 口径"deploy 角色必须填写公网 IP"(沿用 create 既有文案)
- 响应结构:`data = _to_item(runner)`(全字段含 tags/is_local)
- 审计:`runner.update`,detail=`{"changed": [改动字段名], "before_tags": [...], "after_tags": [...]}`
- 错误码族:16005(名称)/16008(标签)复用新建

### 接口:创建(远程/local)改造
- `CreateRunnerRequest` / `CreateLocalRequest` 增 `tags: list[str] = []`;校验同上(16008;deploy+非空 tags → 16008)
- 响应:`_to_item` 形态增 `tags`(远程 create 响应仍含一次性 token,不变;local 响应加 `tags`)

## 服务端行为规格

| 行为 | 规格 |
|---|---|
| 调度匹配(worker) | `pick_runner_db(db, required_role, task_tag=None)`:SQL 取 online+role+容量候选(既有)→ **应用层过滤**:`tags=set(r.tags or [])`;`not tags or task_tag in tags` → 入选;最少负载+前5随机(既有)不变;无匹配 → 日志 `"等待 {task_tag} 专属 Runner"` + None → 既有 8003 |
| 调度匹配(deploy) | task_tag=None,纯 role 过滤,行为零变化 |
| 调用点 | `schedule_and_start` 加 `task_tag: Optional[str]=None` 透传 pick_runner_db;`create_polish_task` 传 "requirement";`start_task` 传 `task.type if task.type in ("requirement","dev","test") else None` |
| tags 校验 | `validate_tags(value)`:必须 list[str] → 去重 → 每值 ∈ {requirement,dev,test};非法 → BizError(16008,"任务类型标签非法:{值}");deploy 行非空 tags → BizError(16008,"deploy Runner 不参与任务类型标签") |
| 编辑状态机 | 存在(404)→ 校验 → 单行 UPDATE(name/max_containers/tags/public_ip)→ flush → 审计;**disabled 行允许编辑**(禁用只挡调度);编辑不影响进程/容器/token_hash |
| 事务 | 编辑单事务(get_db 提交);并发以单行 UPDATE 原子 + 调度实时查库快照兜底 |
| 唯一性 | name 全平台唯一(16005 显式校验,DB 约束兜底);**name 未变时跳过唯一校验**(自撞防护) |
| 响应最小化 | tags/名称/容器数无敏感值;token 永不出现在请求/响应/审计 |
| 存量兼容 | tags=NULL → 兜底;`_to_item` 输出 `tags: r.tags or []`(恒为数组,前端免判) |
| 审计 | `runner.update`(R25 模式 C,operator 在 API 层);detail 只记 tags 前后与改动字段名 |
