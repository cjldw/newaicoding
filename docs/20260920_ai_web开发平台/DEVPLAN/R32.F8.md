# R32.F8:修复 BUG-060 容器重建后 resume 静默失败空回复

> 状态:🔄 进行中(代码完成+真机实证;用户浏览器复验后 verified)
> 模块:M5(runner+后端 container_service)
> 关联:BUG-060

## 根因

容器重建后 tasks.claude_session_id 残留 → 首条消息 `claude --resume <不存在>` →
CLI 报错走 stderr(2>/dev/null 吞)→ stdout 零行 → 空 result 正常结算落库。

## 修复(双层)

1. 平台治本:handle_container_started 置空 claude_session_id(新容器必无旧会话)
2. runner 兜底:返回增 lines 计数;流式 handler 识别「带会话且零行」自动降级
   无会话重跑(首趟零行,二次上泵无重复)

## 验证

- runner 52/52(新增空跑 lines=0 用例;既有相等断言同步 lines 键)
- 真机:会话重置后对话 8.5s 返 pong 落库(14 tokens)
