# R22.F1 修复:四维管理页崩溃——列表契约缺 key 字段(BUG-014)

> 状态:✅(2026-09-22 rd-fix 第 6 轮完成:pytest dashboard 8/8;浏览器实测四维页全部不崩、行渲染正常;verified 迁移 ISSUES.md)

## 描述(bug)

用户报告运行时崩溃:`DimensionPage.tsx` `item.key.slice(0, 8)` → `Cannot read properties of undefined (reading 'slice')`。

**根因**:`dashboard_views.py` 需求端点返回 `req_id`、任务端点返回 `task_id`,前端 `DimensionItem` 契约为 `key` → 永远 undefined。此前列表恒空未触发;有真实项目/需求数据即白屏。

## 实现要点

`backend/app/api/dashboard_views.py` 两处 items 补 `"key": r.req_id / t.task_id`(保留原字段兼容),前端契约零改动。

## 测试验证逻辑与回归结果

1. `pytest -k dashboard`:8/8 全绿
2. API 实测:`GET /dashboard/requirements` items[0] 含 `key`(值=req_id)
3. 浏览器实测:/manage/requirements 渲染 2 行(含用户此前触发崩溃的数据)不崩;tasks/tests/releases 三维同验不崩;截图 fix-dimension-page.png

## 实施轨 + 对应设计稿

- 轨1:无 UI 改动(契约补齐);DimensionPage 沿用并行会话重构后的卡片化结构
