# R1.F2 — 修复 BUG-UI-067:登录页清理 + LOGO 统一居中

## 描述(即 bug)

登录页含 4 段演示/技术文案,视觉噪音大且暴露内部信息;且四张 auth 页 LOGO 不一致(登录页 CSS 方块"旗"字左对齐,注册/忘记密码/重置密码页用 `/logo.svg` 居中)。用户要求:删文案、LOGO 居中、忘记密码与注册页与登录页用一致的 LOGO 图。

## 实施轨 + 对应设计稿

- 实施轨:轨 1 — 视觉原型 `vp/index.html` 登录页(login 段)为样板;删除项为用户指令(优先级高于 vp 原文,若 vp 含同款文案以用户指令为准删除)
- 路由与入口:`/login`、`/register`、`/forgot-password`、`/reset-password`(frontend/src/pages/auth/ 四页)

## 实现要点(根因 + 修复方案)

**根因**:R1 期登录页按早期开发态实现,遗留了演示说明与假数据展示(4 段文案全部硬编码于 `Login.tsx`,非接口数据);LOGO 未抽公共组件,各页各写一套。

**改动清单**(分析底稿 `.scratch/fix-analysis-r15d-auth-icon.md`):

1. `Login.tsx` 删 4 处(全部硬编码):
   - L85-90 品牌副标题 `<span className="muted small">AI 研发流程平台 · 需求启程,一路旗程:需求 → 开发 → 测试 → 发布 → 归档</span>`(保留 `<b>旗程</b>` 外壳)
   - L98-100 `<div className="muted small">手机号 + 密码登录(JWT · access 2h · 短信验证码 V2)</div>`(保留 `<h2>登录</h2>`)
   - L187-192 `<div className="chip-row small">` 整块(含 "GitLab token 已绑定(luowen@gitlab.internal)" 假数据徽章)
   - L196-206 演示账号说明整块 `<div className="small muted">…罗文(超管)…</div>`
2. **LOGO 统一**:提取 `pages/auth/AuthLogo.tsx` 公共组件(`/logo.svg` + 品牌名"旗程",flex-col 居中);四页统一引用;`Login.tsx` 的 login-logo 由横排 CSS 方块改居中竖排(与注册页一致)
3. 辅助链接(忘记密码/注册入口)保留不动;表单逻辑不动

## 渲染核对期望(修复重点:删文案 + LOGO 居中一致)

- `/login` 页面 DOM 不含"AI 研发流程平台 ·""JWT · access 2h""GitLab token 已绑定""演示账号:"四段子串
- 四页首屏均有 LOGO 图(`/logo.svg`),水平居中(login-logo/login-card 内 flex-col items-center)
- 登录表单(手机号/密码/提交)、辅助链接不受影响
