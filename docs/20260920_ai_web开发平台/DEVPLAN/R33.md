- **PRD 引用**(边界定义 + 异常/边界 + 验收标准摘录,下游不读 PRD 全文):
  - **做什么**:`/` 触发下拉能力菜单,分组列出**项目 Skills、平台(内置)Skills(R17)与已启用的 MCP server(R17)**;继续输入按名称过滤;↑↓ 导航、Enter 选中、Esc 关闭;与 `@` 文件补全互斥切换(按首字符 `@`/`/` 分流);**选中后以斜杠原文(`skill-name`/`mcp-name`)随消息透传给容器内 claude CLI 原生执行,平台不做任何技能解释/编排**(Q64);无 Skills 且无 MCP 时不弹菜单(原文发送)
  - **不做什么**:平台不解析/编排/执行技能与 MCP(执行全归容器内 CLI);不做 MCP **工具级**枚举(V2);终端不做斜杠补全;不做自定义斜杠命令的管理界面
  - **字段定义**(菜单项;数据全部来自 R17 既有存储/接口,零新表):
    | 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |

    | type | enum | 是 | - | skill / mcp | 分组依据 |
    | name | string | 是 | - | 非空 | 斜杠调用的名称原文 |
    | source | enum | 是 | - | project / platform | Skills 来源(MCP 恒 project 配置) |
    | description | string | 否 | - | - | 菜单副标题(既有字段,缺失则不显示) |
  - **异常与边界场景**:
    - 消息以斜杠原文透传,平台**不校验名称存在性**(CLI 侧对未知命令自有提示)
    - MCP server **不是 CLI 的斜杠原生命令**(MCP prompts 的 CLI 原生形式为 `/mcp__server__prompt`):选中 MCP 插入 `/server名` 透传后为**文本语境**,由模型自主判断是否调用该 server(配置已在容器内注入,R17/D15);验收标准 3 以"回复体现参与"为尽力判据,不保证每次触发
  - **验收标准**:
    1. 任务工作台 AI 对话输入 `/` 弹出分组菜单(项目 Skills/平台 Skills/MCP),过滤与键盘导航可用
    2. 选中 skill 发送后,容器内 claude 按该 skill 执行(以回复内容可辨认为准)
    3. 选中 MCP server 发送后,回复体现该 server 参与执行
    4. 无 Skills/MCP 时 `/` 不弹菜单,消息正常发送
