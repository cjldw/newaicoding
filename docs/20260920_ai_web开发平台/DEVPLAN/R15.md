## PRD 引用

### 边界定义

- **做什么**:
  - 预览泛域名 `*.{preview_base_domain}`(preview_base_domain **平台设置可配**,Q28/R2,默认示例 `preview.coding-console.zhanqitv.com.cn`;预览,任务级)
  - 部署域名 `{deploy_host}:{port}`(deploy_host 默认 `{slug}.{deploy_base_domain}`;**发布任务可自定义,Q29**;按 Host 精确匹配路由)
  - 动态路由注册/摘除(容器端口监听驱动 / 部署事件驱动)
  - **路由 upstream 直连 Runner 宿主机映射端口**:`http://{runner_host}:{runner_mapped_port}`(按 ARCH D20/PRD Q25:**取消 Runner 本地代理层**,无 Runner 层 Nginx;preview 走网关转发,deploy 公网直达 `runner_host:deploy_port`)
  - 预览路由**鉴权**,部署路由**公开**
  - WebSocket 透传(HMR/TTY)
  - 流量/访问日志
- **不做什么(V1)**:
  - HTTPS(HTTP only;含自定义域名证书)
  - CDN
  - WAF/防火墙(V1 信任内网/基础防护即可)
  - 域名级高级能力(DNS 托管 / 泛域名证书 / 多域名绑定;仅支持发布任务级一个自定义 deploy_host,Q29)

| 场景/条件 | 行为/规则 | 结果/去向 |
|---|---|---|

### 异常与边界场景

- 上游 5xx → 502 页面带项目名与日志链接
- 单 host QPS 上限(防爬/防滥用,默认 100)
- 端口池 `10000-10099`(100 个端口,够 20 个项目 × 5 个部署)
- **Runner 宿主机端口冲突**:Runner 启动容器时分配随机宿主机端口(范围 20000-29999),冲突自动重试(无本地代理层,按 D20)
- **自定义 deploy_host 未解析 DNS**(Q29):路由注册成功但外网不可达(创建侧不阻塞,R7);域名解析到网关后立即生效
- **preview_base_domain 变更**(Q28):仅影响之后注册的预览路由;存量路由按注册时 host 保留至摘除(任务结束自然清理)
- 泛域名 `*.{preview_base_domain}` 的 wildcard DNS 解析由运维配置(部署平台时一次性设置)

1. 预览鉴权正确,部署公开

### 服务端行为规格

#### 注册路由

1. 平台监听容器端口监听事件(Runner 回报 `port_listening`)
2. 平台查询容器的 `runner_id` + `runner_host_port_*`
3. 拼接 upstream:`http://{runner_host}:{runner_mapped_port}`
4. 平台写 `routes` 表(status=active)
5. 平台通知网关(Nginx/Traefik)动态加载路由配置

#### 摘除路由

1. 平台监听容器端口关闭事件(Runner 回报 `port_closed`)或容器销毁事件
2. 平台更新 `routes` 表(status=inactive)
3. 平台通知网关卸载路由配置

#### 访问 preview

1. 用户访问 `http://{slug}--{taskId}--{port}.{preview_base_domain}`(preview_base_domain 平台设置,Q28)
2. 网关查 `routes` 表(host 匹配 + type=preview + status=active)
3. 校验 JWT + 项目成员(R12)
4. 鉴权通过 → 转发到 upstream(Runner 宿主机映射端口,直达容器)
5. 鉴权失败 → 返回 403

#### 访问 deploy

1. 用户访问 `http://{deploy_host}:{port}`(默认域名或发布任务自定义域名,Q29)
2. 网关查 `routes` 表(**按 Host 精确匹配**,含自定义域名 + type=deploy + status=active)
3. **不鉴权**(公开访问)
4. 转发到 upstream(deploy Runner 宿主机映射端口,直达容器)
