## 描述(bug)

## 实现要点(根因 + 修复方案)

1. 隔离测试库 `aicoding_test` 已创建(同 MySQL 实例 120.27.217.194:3306,develop 账号具备全局 CREATE 权限)
2. `tests/conftest.py`:在 engine/settings 初始化**之前**覆盖 `DATABASE_URL` 环境变量指向 `aicoding_test`(注意:.env 加载顺序,确保 app settings 读到的是覆盖值;用 `os.environ[...] = ...` 且先于 `from app...` 导入,或用 conftest 顶部的导入前钩子)
3. 会话级 fixture:启动时确保 schema 存在——优先 `alembic upgrade head`(以测试库 URL 运行);若 alembic 与 env.py 耦合难拆,退回 `Base.metadata.create_all`(以实测可行为准)
4. 既有清理逻辑保留不变(此时清的是测试库)
5. **防再犯护栏**:conftest 增加一道断言——解析生效 DATABASE_URL,若库名不是 `aicoding_test` 则 `pytest.exit("拒绝在非测试库上运行", returncode=1)`(防止未来环境变量覆盖失效时再次误伤 dev 库)
