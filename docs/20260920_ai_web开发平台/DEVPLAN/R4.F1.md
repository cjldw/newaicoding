# R4.F1 — 任务工作台三面板增强:全屏 / 保存 / 滚动(BUG-UI-064)

> 来源:用户指令 2026-09-23("任务页面的所有需求:terminal, ai对话, 文本编辑器可以全屏,保存,滚动")
> 状态:✅ fixed(2026-09-23;静态核对全过 + tsc 零错 + build 8.25s,verified 待浏览器实渲染)

## 描述(即需求)

任务工作台右侧/中央三面板能力补齐:
- **Terminal**(R9):全屏、会话日志导出(保存)、滚动(scrollback 已有,验证全屏尺寸自适应)
- **AI 对话**(R4/R5):全屏、对话记录导出 Markdown(保存)、滚动(已有自动滚底,验证)
- **文本编辑器**(R11):全屏、显式保存按钮(已有 500ms 防抖自动保存 + Ctrl+S)、滚动(Monaco 自带)

## 实现要点

- **全屏机制**:TaskDetail 持有 `fs: null|'chat'|'terminal'|'editor'` 状态;各面板根节点按 prop 追加 `fixed inset-0 z-[60]` 类(CSS 提升,**面板不重挂载**——xterm 缓冲/聊天记录/编辑器实例全保留);Esc 退出
- **保存**:编辑器 = 工具栏「保存」按钮(onChange 草稿态 + saveFile mutation,自动保存与 Ctrl+S 保留);Terminal = 导出 .log(xterm buffer 序列化);AI 对话 = 导出 .md(transcript)
- **滚动**:各面板维持 `min-h-0` 链;Terminal ResizeObserver 已自动 refit
- 不改数据流/后端;TaskChat 与 TerminalPanel 有并行会话未提交改动,只增不重写
