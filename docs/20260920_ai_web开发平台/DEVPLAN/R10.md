## PRD 引用

### 边界定义

- **做什么**:
  - 端口探测:5173/8000 有监听 → 自动注册网关路由
  - URL 形态:`http://{slug}--{taskId}--{port}.{preview_base_domain}`(HTTP,任务级唯一)
  - iframe 内嵌 + 新窗口打开
  - HMR WebSocket 透传
- **不做什么**:
  - HTTPS
  - 自定义端口
  - 预览公开访问(仅项目成员;公开访问走 R7)
  - 无任务时的"项目级预览"

### 字段定义

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| port | int | 是 | - | 5173/8000 |
| subdomain | string | 是 | `{slug}--{taskId}--{port}` | 任务级唯一 |
| upstream | string | 是 | `http://{runner_host}:{runner_mapped_port}` | |
| status | enum | 是 | inactive | active/inactive |

### 交互规则

| 场景/条件 | 行为/规则 | 结果/去向 |
|---|---|---|
| 端口监听 | 注册路由 → active | 预览亮起 |
| 端口关闭 | 摘除路由 → inactive | 显示"服务未启动" |
| 访问预览 | 鉴权:登录 + 项目成员 | 非成员 403 |
| 容器销毁 | 路由摘除 | URL 不可访问 |
| iframe 加载失败 | 提示重试 + 新窗口 + 看终端日志 | |

### 异常与边界场景

- 端口被占但非 HTTP:健康检查失败 inactive
- 泛域名证书 `*.{preview_base_domain}`(虽 HTTP only,但备未来升级)

### 验收标准

1. 容器内起 5173 服务 ≤ 3s 预览可见
2. 代码改动 HMR 自动刷新
3. 非成员访问被拒
4. 容器销毁后预览 URL 失效

### 接口契约

**接口契约** 总览——**响应结构**统一外层 `{"code": 0, "data": ..., "message": "ok"}`(错误时 `code` 为业务错误码、`message` 为提示文案);字段级结构以下方各接口小节的请求/响应示例为准:

| 接口范围 | 响应结构约定 |
|---|---|
| 本需求点全部接口(下方小节逐一列出) | 统一外层 `{code, data, message}`;分页接口 `data` 含 `{items, total}` |

(预览接口复用 R15 的网关,不单独定义)

### 权限矩阵

| 操作 | owner | editor | viewer | 非成员 |
|---|---|---|---|---|
| 访问预览 | ✅ | ✅ | ✅ | ❌(403) |

### 服务端行为规格

#### 端口探测

1. Runner 监听容器端口(5173/8000)
2. 端口开始监听 → Runner 回报平台:
   ```json
   {
     "type": "port_listening",
     "container_id": "docker_id",
     "port": 5173
   }
   ```
3. 平台注册路由(R15):
   - host: `{slug}--{taskId}--{port}.{preview_base_domain}`(preview_base_domain 平台设置可配,Q28/R2)
   - upstream: `http://{runner_host}:{runner_mapped_port}`
   - type: preview
   - auth_required: true
4. 平台更新 `routes` 表(status=active)

#### 访问预览

1. 用户访问 `http://{slug}--{taskId}--{port}.{preview_base_domain}`
2. 网关校验 JWT + 项目成员(R12)
3. 鉴权通过 → 网关**直连** `http://{runner_host}:{runner_mapped_port}`(容器宿主机映射端口,无本地代理层,按 ARCH D20/PRD Q25)
4. 鉴权失败 → 返回 403

### 页面交互流程

#### 打开预览流程

1. 用户进入任务工作台 → 预览区显示"服务未启动"
2. AI 在容器里跑 `npm run dev`(起 5173 服务)
3. Runner 探测到端口监听 → 回报平台 → 平台注册路由
4. 预览区显示 iframe,加载预览 URL
5. 用户点"在新窗口打开" → 打开新 Tab
