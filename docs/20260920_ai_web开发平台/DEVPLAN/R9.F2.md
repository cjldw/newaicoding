# R9.F2:修复 BUG-046 终端 xterm 崩溃(safeFit 守卫)+ BUG-UI-070 终端滚动条美化

> 状态:✅ 完成(2026-09-24 第 23/24 轮;BUG-046 代码闭环+原崩溃真机实证消失;BUG-UI-070 verified 迁移 ISSUES.md)
> 模块:M5 Web 终端(frontend/src/components/Terminal.tsx + globals.css;波及 R26 Runner 终端 Dialog);**后端/WS 协议零改动**
> 关联:BUG-046(崩溃)+ BUG-UI-070(美化);用户报障+指令 2026-09-24(rd-fix 第 23 轮)

## 描述(BUG)

- **复现**:超管 Runner 管理 → 终端(R31.F1 后宿主 shell 会话真开)→ Dialog 打开瞬间 console 报 `RenderService.ts:52 Uncaught TypeError: Cannot read properties of undefined (reading 'dimensions')`,终端白屏不可用;任务工作台新建终端同样暴露风险
- **根因**(分析见 `.scratch/fix-analysis.md` § 第 23 轮):Terminal.tsx 初始 fit 单 rAF 无守卫;ResizeObserver observe 首帧立即回调且无条件 fit+sendResize——Runner 终端 Dialog 150ms 入场动画期间容器尺寸未稳,fit() 访问未就绪的 xterm RenderService.dimensions → TypeError。ws 报错为连带症状

## 实现要点

1. **Terminal.tsx safeFit 统一入口**:disposed 守卫 + `el.clientWidth/Height>0` 尺寸守卫 + try/catch 兜底(渲染器未就绪忽略本轮,RO 下帧重试);fit 成功才 sendResize
2. 初始 fit 改**双 rAF**(等 Dialog 动画/布局稳定后再首次 fit)
3. ResizeObserver 回调改走 safeFit(不再裸调)
4. **globals.css 纯追加** `.xterm-viewport` 滚动条:WebKit 8px/thumb rgba(255,255,255,.18) 4px 圆角/hover .32/track 透明;Firefox scrollbar-width thin + scrollbar-color——终端底色恒 #1e1e1e,双主题通用
5. 不改:WS 连接/重连/数据流、R4.F1 全屏(不重挂载)、R9.F1 claude 会话、R26 判据 11 断线文案
