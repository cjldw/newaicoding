# R16.F2 修复:Runner 表格补 .card 包裹(BUG-UI-003 重开)

## 状态:⬜

## 描述(bug)

BUG-UI-003(重开,用户确认 border 不对):/admin/runners 表格是裸 `.scrollx + .tbl`,无 `.card` 外层包裹——表格无卡片背景/边框/圆角/内边距,与 /admin/users、/admin/audit-logs(表格在 `.card` 内)视觉不一致,用户观感即"表格 border 不对"。

**运行时证据(2026-09-22 Playwright 截图 recon-admin-runners.png)**:表头灰条与行直接顶到内容区边缘,无卡片描边;对照 /admin/users 表格有圆角描边卡片。

## 实现要点(根因 + 修复方案)

**根因**:`frontend/src/pages/admin/RunnerManagement.tsx` 表格容器层级为 `<div className="scrollx">`(裸),缺 vp 统一模式的 `.card` 外层。

**修复**(对齐 vp 统一模式 `.card > .scrollx > table.tbl`,与 UserManagementPage.tsx / AuditLogsPage.tsx 同构):
```tsx
<div className="card">
  <div className="scrollx">
    <Table className="tbl">...</Table>
  </div>
</div>
```
Runner 页当前无分页,不加 `.card-foot`(如有表级提示再追加)。

## 测试验证逻辑(修复后按此回归)

Playwright 断言 /admin/runners:
1. `.card > .scrollx > table.tbl` 存在且可见
2. `.card` 计算样式含边框与圆角(与 /admin/users 的 `.card` 一致,抽查 border-top-width 与 border-radius 相同)
3. 表格数据渲染不受影响(runner 行数/操作按钮仍可见)
