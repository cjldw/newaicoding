# R2.F8 — 修复 BUG-UI-068:项目卡片点击进详情 + 全页面大标题补 icon

> 来源:BUGS.md BUG-UI-068(用户指令 2026-09-23 rd-fix 第 15 轮)
> 状态:✅ fixed(2026-09-23,验证 `.scratch/rd-fix-r15/ui-check.md`;留痕:路由实为 /settings/gitlab-token;KnowledgeBaseView 豁免)

## 描述(即 bug)

① 项目列表点击项目项需能打开项目详情——现状用 `window.location.hash` 跳转(`ProjectList.tsx` L111),与 BrowserRouter 不匹配,可能不生效;② 用户重申"主页面内容大标题都带 icon 风格"——R2.F2 曾做 12 页,仍有页面遗漏。

## 实施轨 + 对应设计稿

- 实施轨:轨 1 — `vp/index.html`(各页 page-head 均为 icon + 标题结构)
- 路由与入口:全部主页面(清单见下);项目卡片入口 `/projects` → `/projects/:id`

## 实现要点(根因 + 修复方案)

**根因**:① ProjectList 卡片点击用 hash 跳转,react-router v6 BrowserRouter 下应走 `useNavigate`;② R2.F2 首轮只覆盖了部分页面,settings/requirements/tasks 子页、ProjectDetail、McpConfigManagement 等漏网(分析底稿 `.scratch/fix-analysis-r15d-auth-icon.md` §2.3)。

**改动清单**:

1. `ProjectList.tsx` L111:`window.location.hash = ...` → `useNavigate()` 的 `navigate(`/projects/${item.project_id}`)`
2. **补 icon 惯例**(对齐既有页面:`<div className="page-head"><h1 className="flex items-center gap-2"><XIcon size={18} /> 标题</h1></div>`),12 页清单:
   - settings 三页(ProfileSettings `<User />` / GitLabTokenSettings `<KeyRound />` / NotificationSettings `<Bell />`)——均无 page-head 结构,统一补 `page-head + h1` 外壳(h2→h1)
   - requirements 三页(RequirementList `<ClipboardList />` / ArchivePage `<Archive />` / RequirementDetail `<FileText />`)
   - tasks 三页(TestCasesReview `<CheckSquare />` / TestReport `<BarChart3 />` / DeployStatus `<Rocket />`)
   - projects/ProjectDetail `<FolderKanban />`、projects/McpConfigManagement `<Plug />`
   - pages/Dashboard.tsx(占位页)`<LayoutDashboard />`(低成本顺手补)
   - icon 选型可按语义微调,但必须 lucide-react、size 18、与 h1 同行(gap-2)
3. KnowledgeBaseView(文档详情)豁免(正文视图无页头惯例,与 BUG-UI-063 面包屑处理一致);NotificationCenter 已有 icon 不动

## 渲染核对期望(修复重点:点击跳转 + 12 页 icon)

- 项目卡片点击后 URL 变为 `/projects/{id}` 且页面渲染项目详情(非整页刷新、非无反应)
- 12 页逐一断言:h1(或页头首行)内含 svg icon 元素且与标题同排

## 设计规范

page-head/h1/gap-2 惯例值与既有 15 个已带 icon 页面逐值一致;不新增 CSS 类。
