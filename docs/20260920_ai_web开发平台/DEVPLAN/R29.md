## PRD 引用

### 边界定义(摘录)

- **做什么**:① 侧栏底部常驻「平台导览」卡片(对齐 vp 原型 `.tour`);② 首次登录自动弹出导览弹窗,完成后不再自动弹出;③ 静态链接列表(编号步骤,点击跳转对应页面);④ 步骤动态生成(根据当前用户可访问数据动态显示/隐藏);⑤ 完成标记 localStorage `tour_completed`
- **不做什么**:不做交互式分步引导(driver.js 高亮元素+浮层);不做视频教程;不做导览进度跟踪;不做多语言导览

### 异常与边界场景(摘录 + 挖掘)

- 新用户无项目/需求/任务:对应步骤不显示,仅显示 always 步骤
- 清理浏览器缓存:`tour_completed` 丢失,重新弹出一次(可接受)
- 导览过程中页面跳转:弹窗关闭,下次手动打开重新开始
- 链接目标页面数据已删除:正常 404 处理
- (挖掘·引用)导览步骤数据获取失败:某维度 API 失败时,该维度步骤降级为不显示(不阻塞其他步骤)

### 验收标准(摘录)

1. 首次登录自动弹出导览,完成后不再弹出
2. 步骤根据用户数据动态显示/隐藏
3. 点击步骤正确跳转
4. 侧栏入口常驻,可随时手动打开
5. 跳过/完成后 localStorage 标记正确

## 接口契约

**接口契约** 总览——响应结构统一外层 `{"code": 0, "data": ..., "message": "ok"}`(无新建接口,复用现有):

| 接口 | 类型 | 响应结构(data 内容) | 用途 |
|---|---|---|---|
| GET /api/projects | 复用现有 | `{list: Project[], total: number}` | 步骤3:获取第一个项目 |
| GET /api/projects/{project_id}/requirements | 复用现有 | `{list: Requirement[], total: number}` | 步骤4:获取第一个需求 |
| GET /api/requirements/{req_id}/tasks | 复用现有 | `{list: Task[], total: number}` | 步骤5/6/7:获取任务列表 |
| GET /api/requirements/{req_id}/archive | 复用现有 | `{timeline: ArchiveNode[], summary: object}` | 步骤8:验证归档存在 |

- **调用策略**:导览弹窗打开时并行请求 5 个维度(项目/需求/开发任务/测试任务/发布任务),每维度取第一条数据
- **降级**:某维度 API 失败或无数据,该维度步骤不显示

## 实现要点

### 前端组件

1. **TourDialog 组件**(新建 `frontend/src/components/TourDialog.tsx`):
   - Modal 弹窗,标题"平台导览"
   - 编号步骤列表(1-N 动态生成)
   - 底部按钮:"完成导览"、"跳过"
   - 步骤点击:关闭弹窗,navigate 到对应链接

2. **步骤数据获取**(`useTourSteps` hook):
   - 并行调用 5 个 API 获取数据
   - 按条件过滤生成步骤数组
   - 缓存:react-query 管理,避免重复请求

3. **首次自动弹出逻辑**(MainLayout.tsx):
   - useEffect 检查 localStorage `tour_completed`
   - 无标记则自动打开 TourDialog
   - 完成/跳过后写入标记

4. **侧栏入口接线**(MainLayout.tsx:224-228):
   - 「开始导览」按钮 onClick 打开 TourDialog
   - 常驻显示,无论是否已完成

### 步骤生成逻辑

```typescript
interface TourStep {
  n: number           // 编号
  title: string       // 标题
  link: string        // 跳转链接
}

// 生成步骤数组
const steps: TourStep[] = [
  { n: 1, title: '工作台 · Dashboard', link: '/' },
  { n: 2, title: '四维管理 · 需求管理', link: '/manage/requirements' },
  // 条件步骤:有数据才添加
  ...(project ? [{ n: 3, title: `项目 · ${project.name}`, link: `/projects/${project.project_id}` }] : []),
  ...(requirement ? [{ n: 4, title: `需求 · ${requirement.title}`, link: `/requirements/${requirement.req_id}` }] : []),
  ...(devTask ? [{ n: 5, title: '开发工作台', link: `/tasks/${devTask.task_id}` }] : []),
  ...(testTask ? [{ n: 6, title: '测试任务', link: `/tasks/${testTask.task_id}` }] : []),
  ...(releaseTask ? [{ n: 7, title: '发布任务', link: `/tasks/${releaseTask.task_id}` }] : []),
  ...(archive ? [{ n: 8, title: '归档时间线', link: `/requirements/${reqId}/archive` }] : []),
  { n: 9, title: '知识条目', link: '/knowledge' },
  // 超管额外步骤
  ...(isSuperadmin ? [{ n: 10, title: '用户管理 / 审计日志', link: '/admin/users' }] : []),
]
```

## 页面交互流程

- **首次自动弹出**:登录成功 → 跳转 Dashboard → useEffect 检测无 `tour_completed` → 自动打开 TourDialog → 用户点击"完成导览"或"跳过" → 关闭弹窗,写入 localStorage → 后续不再自动弹出
- **手动打开**:侧栏底部点击「开始导览」→ 打开 TourDialog → 点击步骤链接 → 关闭弹窗,跳转对应页面
- **步骤点击**:点击某步骤 → 关闭弹窗 → react-router navigate 到链接地址
