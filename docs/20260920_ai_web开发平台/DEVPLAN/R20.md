## PRD 引用

### 边界定义

- **做什么**:
  - 项目级**文档空间**形态的知识库(wiki 形态),与 R14 知识条目**并存**(条目级 vs 文档空间级,Q18)
  - 两种创建方式:**a) 空模板**(平台内可编辑,存平台数据库);**b) 目录导入**(读取项目绑定仓库的多个目录下 .md 文件生成快照,**平台内只读** + 手动同步,Q19)
  - 知识库 CRUD(单项目可建多个)
  - **空模板类型**:树形目录中新增/编辑/删除/拖拽排序页面;Markdown 编辑器(复用 R11 Monaco)+ 预览;内容存**平台数据库**
  - **目录导入类型**:选仓库(项目已绑定的任一 repo)→ 选分支(默认项目默认分支)→ **多选目录**(GitLab API 目录树浏览多选,或手动输入路径)→ 平台用 **bot token** 调 GitLab API 拉取目录下全部 .md 文件(**保留目录层级**,Q20)→ 生成树形页面快照入库
  - **导入型只读**:仅可查看/搜索;"重新导入(同步)"按钮按原 source_config 重新拉取并覆盖
  - 查看:左侧树形目录(可折叠/搜索定位)+ 右侧 Markdown 渲染(代码高亮);知识库内**标题 + 全文搜索**
  - 导入为**后台任务**,前端显示进度,完成后通知(R18 站内信 + toast)
- **不做什么**:
  - 不做导入型的平台内编辑 / 回写 repo(修改仓库文件后走"重新导入"刷新)
  - 不做自动定时同步(仅手动)
  - 不做平台级知识库空间(V1 仅项目级;平台级仍只有 R14 知识条目)
  - 不做页面级权限 / 分享链接 / 评论
  - 不做非 .md 文件导入(图片等资源不导入,渲染时相对路径资源标注失效)
  - 不做页面版本历史 / 回收站 / 导出 PDF(与 R14"不做版本管理"原则一致)
  - 不做修改 source_config(换目录/分支需删库重建)
  - 空模板与导入型**不可互转**;导入型不可追加平台侧页面

### 权限(PRD 原样摘录,挂接 R12 矩阵)

查看/搜索=全部项目成员;建库/编辑空模板页面/导入/同步/删库=owner/editor;超管按 R19 等同 owner;repo_import 的写操作后端 403 双重拦截

### 异常与边界场景

- 平台限制(可配置):单知识库页面 ≤ 500、单文件 ≤ 1MB,超限跳过并在导入结果中提示
- 导入快照后**相对路径图片/链接失效**:渲染时标注"资源未导入";绝对 URL 正常渲染
- path 冲突(非法字符/重名):自动加后缀 `-1`
- 导入超时(5 分钟)失败:可重试;已拉取部分不入库(整体成功或失败)
- 多人并发编辑同一页面:后保存覆盖前者(与 R11 同策略,不锁定)
- 删除仓库内源文件后同步:该页面从知识库中移除(以仓库为准)
- (挖掘)并发同步互斥:同一知识库同时仅允许一个导入/同步任务在跑,重复触发返回 20007"导入进行中"
- (挖掘)同步过程中用户浏览:读旧快照不受影响(新数据事务内整体替换后可见)

### 验收标准

1. 空模板知识库:新建页面、Markdown 编辑保存、渲染正确(代码高亮)
2. 导入型:从指定仓库多个目录导入 .md,保留目录层级成树
3. 导入型只读:前端无编辑入口,API 写操作 403
4. 重新导入刷新内容,last_synced_at 更新
5. 仓库不可用时同步失败但快照保留
6. 树形导航 + 全文搜索可用
7. viewer 只读,前后端双重拦截;editor 可建库编辑,与 R12 矩阵一致

### 接口契约

**接口契约** 总览——**响应结构**统一外层 `{"code": 0, "data": ..., "message": "ok"}`(错误时 `code` 为业务错误码、`message` 为提示文案);字段级结构以下方各接口小节的请求/响应示例为准:

| 接口范围 | 响应结构约定 |
|---|---|
| 本需求点全部接口(下方小节逐一列出) | 统一外层 `{code, data, message}`;分页接口 `data` 含 `{items, total}` |

#### 1. 知识库列表/创建

- 类型:新建
- 路径与方法:`GET /api/projects/{project_id}/knowledge-bases`、`POST` 同路径
- 鉴权:GET=项目成员;POST=`require_project_role('editor')`
- POST 请求体:

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string(64) | 是 | 同项目唯一 |
| description | string(255) | 否 | |
| source_type | string | 是 | blank / repo_import |
| source_config | object | repo_import 必填 | `{repo_id: uuid, branch: string, paths: string[]}`;repo 必须属于本项目;branch 缺省=项目默认分支 |

- 响应结构(创建):

| 字段 | 类型 | 说明 |
|---|---|---|
| kb_id | uuid | |
| name / description / source_type / source_config / import_status | - | 创建 repo_import 时 import_status=importing(后台任务已入队) |

- GET 响应:`items[]`(不含 content)+ `total`
- 错误码:`20001` 名称重复;`20005` source_config 无效(repo 不属于本项目/路径格式非法);`19002/12006` 越权

#### 2. 知识库详情(树)/改名/删除

- 类型:新建
- 路径与方法:`GET / PATCH / DELETE /api/projects/{project_id}/knowledge-bases/{kb_id}`
- 鉴权:GET=项目成员;PATCH/DELETE=editor 以上
- GET 响应:`{kb_id, name, description, source_type, source_config, import_status, import_error, last_synced_at, docs: [{doc_id, title, path, sort_order}](不含 content)}`
- 错误码:`20004`-段无;删除无特殊保护(二次确认在前端);`20006` knowledge_bases 记录不存在(404 语义)

#### 3. 导入(首次失败重试)/ 重新导入(同步)

- 类型:新建
- 路径与方法:`POST /api/projects/{project_id}/knowledge-bases/{kb_id}/import`、`POST .../sync`
- 鉴权:editor 以上
- 请求体:无(按 source_config)
- 响应:`{kb_id, import_status: "importing"}`——**后台任务**,完成经 R18 通知;前端轮询接口 2(3s 间隔)兜底刷新
- 错误码:`20007` 导入进行中(并发互斥);`20006` 不存在;source_type=blank 调用 → `20005`(blank 无可导入配置)

#### 4. 页面树/新建页面(blank)

- 类型:新建
- 路径与方法:`GET / POST /api/knowledge-bases/{kb_id}/docs`
- 鉴权:GET=项目成员;POST=editor 以上 **且 source_type=blank**(repo_import → 403 `20002`)
- POST 请求体:`{title: string(128), parent_path: string(可空,空=根级)}`
- POST 响应:`{doc_id, title, path(=parent_path + '/' + slug(title),冲突自动 -1), sort_order}`
- 错误码:`20002` 导入型只读;`20003` 页面数超限(500);`20001`-段 path 冲突由服务端自动消解,不报错

#### 5. 页面读/改/删

- 类型:新建
- 路径与方法:`GET / PUT / DELETE /api/knowledge-bases/{kb_id}/docs/{doc_id}`
- 鉴权:GET=项目成员;PUT/DELETE=editor 以上且 blank
- GET 响应:`{doc_id, kb_id, title, path, content, sort_order, source_file_path, updated_by, updated_at}`
- PUT 请求体:`{title?, content?}`(后保存覆盖前者,不锁定);响应:`{doc_id, updated_at}`
- 错误码:`20002` 导入型只读(PUT/DELETE);`20006` 页面不存在

#### 6. 库内搜索

- 类型:新建
- 路径与方法:`GET /api/knowledge-bases/{kb_id}/search`
- 鉴权:项目成员
- 请求参数:`q`(必填,1-64 字)、`page` / `page_size`(默认 20,上限 50)
- 响应:`items[]`(`{doc_id, title, path, snippet(命中片段,前后各 60 字符,<em> 高亮标记)}`)+ `total`
- 实现:MySQL `FULLTEXT` `MATCH(title, content) AGAINST('{q}' IN NATURAL LANGUAGE MODE)`;**排序固定按相关度,不开放自定义排序**(查询域#8)

### 服务端行为规格(负向探查结论)

| 行为 | 规格 |
|---|---|
| 导入流程(异步域) | 入队(D7)→ `import_status=importing` → bot token 调 `GET /api/v4/projects/{repo_id}/repository/tree?recursive=true` → 过滤 `paths` 前缀下 `.md` → 逐文件 `raw` 拉内容 → **事务内整体替换**(先删旧 docs 再插新,整体成功或失败,失败保留旧快照)→ `import_status=done` + `last_synced_at=now()` → R18 通知(站内信 + toast,接收人=触发人 + 项目 owner);完成判定:`import_status` 变为 done/failed 且通知发出;轮询上限:任务侧 5 分钟超时强制 failed |
| 限制与跳过 | 单文件 > 1MB:跳过并计入导入结果(通知内容列出);页面总数 > 500:超出部分跳过并提示;目录不存在/无 .md:该路径跳过;全部为空 → 整体失败(import_status=failed + import_error) |
| 同步对齐 | 以仓库为准:源文件已删 → 对应页面删除;新增文件 → 新增页面;内容变更 → 覆盖;path 冲突自动 `-1` |
| 并发互斥 | 同一 kb 已有 importing 任务时,再触发 import/sync → `20007`;不同 kb 可并行 |
| 导入型只读 | 后端在写操作入口按 `source_type='repo_import'` 拦截 403 `20002`(**角色不豁免,超管同限**);前端隐藏编辑入口(双重拦截) |
| 唯一性与冲突 | `UNIQUE(project_id, name)` 重复建库 → `20001`;`UNIQUE(kb_id, path)` 冲突自动后缀 `-1`(不报错);非法字符(`/` `\` 空格等)在 path 生成时转 `-` |
| 删除保护/引用 | 删库直接删(级联删 docs,波及范围=该库全部页面,二次确认文案写明);**不影响 GitLab repo**;R14 知识条目与本库无引用关系(并存,命名隔离) |
| 悬空引用 | source_config.repo_id 必须属于本项目且未解绑(创建时校验);解绑后快照可读、同步失败(20005 提示具体原因:仓库已解绑) |
| 分页/排序边界 | page<1 按 1;page_size 上限 50(搜索)/ 列表接口不开放 pageSize>100;排序固定(列表=updated_at 倒序,搜索=相关度),不开放自定义排序字段 |
| 响应最小化 | 列表/树接口不返回 `content`(大字段仅详情返回);不返回 source_config 内部敏感信息(仅 repo_id/branch/paths,无 token) |
| 并发编辑 | blank 页面 PUT 后保存覆盖前者(与 R11 同策略,不锁定;前端保存前提示多人编辑风险?)——V1 不提示,直接覆盖(PRD 口径) |
| 存量兼容 | 全新表,不适用 |

### 页面结构说明

#### 项目内知识库列表 `/projects/{project_id}/knowledge`(Tab,与 R14 知识条目 Tab 并存,命名隔离:"知识库"为本需求点,"知识条目"为 R14)

- **区块结构**:
  1. **操作栏**:右侧"新建知识库"按钮(primary)
  2. **卡片网格**:每卡片=名称 + 类型徽章(空模板/目录导入)+ 同步状态徽章(导入型)+ 页面数 + 更新时间;点击卡片进入阅读页
  3. **新建知识库对话框**:类型选择(Radio:空模板/目录导入)→ 空模板:名称+描述;目录导入:名称+描述+仓库下拉(项目绑定 repo)+ 分支下拉(默认项目默认分支)+ 目录多选(GitLab 目录树浏览多选 + 手动输入路径行,可增删)

#### 知识库阅读页 `/projects/{project_id}/knowledge-bases/{kb_id}`

- **区块结构**:
  1. **顶部栏**:面包屑(项目 / 知识库 / 页面标题)+ 导入型:同步状态徽章 + last_synced_at + "重新导入"按钮(editor 可见)+ 搜索框(库内,防抖 300ms);blank:editor 可见"新建页面"按钮
  2. **左侧树形目录**(宽 260px,可折叠):搜索定位输入 + 树(目录/页面节点,支持拖拽排序——仅 blank);导入型只读无拖拽
  3. **右侧内容区**:Markdown 渲染(代码高亮,`react-markdown` + `remark-gfm` + highlight);相对路径资源标注"资源未导入"占位框
  4. **编辑态**(blank + editor):内容区切换"查看/编辑"Tabs → Monaco(`Editor.tsx`,R11)+ "预览"分屏 + "保存"按钮(primary)
- **本需求点改动范围**:全新页面,无既有区块改动

#### 导入进度呈现

- 创建/同步触发后:阅读页顶部徽章"导入中"(转动图标);列表卡片同步徽章;完成 → R18 toast + 徽章变"已同步";失败 → toast 含 import_error + 保留旧内容

### 页面交互流程

- 创建空模板:项目内知识库 Tab 点"新建知识库" → 对话框选"空模板" → 填名称/描述 → 点"创建" → 成功关对话框 → 跳转阅读页(空树)→ 引导浮层"新建页面"
- 创建导入型:对话框选"目录导入" → 选仓库 → 选分支 → 多选目录 → 点"创建" → 成功关对话框 → 回列表 → 卡片徽章"导入中" → 完成后 toast(R18)→ 点击卡片进阅读页
- 查看页面:左树点页面 → 右侧渲染 `GET docs/{doc_id}`;树上搜索框输入 → 过滤树节点(前端本地)
- 编辑页面(blank):内容区切"编辑"Tab → Monaco 编辑 → 点"保存" → `PUT docs/{doc_id}` → toast"保存成功"→ 留在编辑态;切"查看"回到渲染
- 新建页面(blank):点"新建页面" → 对话框填标题(+父目录)→ 创建 → 树刷新并选中新页面 → 进入编辑态
- 拖拽排序(blank):树节点拖拽 → 松手 → `PUT docs/{doc_id}`(仅 sort_order/parent_path)→ 树刷新
- 同步:点"重新导入" → 确认对话框("将按原配置重新拉取,仓库为准,平台内修改将丢失"——导入型本就只读,文案="将重新拉取仓库内容覆盖")→ 确定 → 徽章"导入中" → 完成 toast
- 删除知识库:列表卡片悬浮 → 点删除图标 → 确认对话框("确定删除知识库 {name} 吗?其下 N 个页面将一并删除,不影响 GitLab 仓库")→ 确定 → 回列表
- 搜索:顶部搜索框输入(防抖 300ms)→ 下拉显示命中页面(snippet 高亮)→ 点击 → 树定位 + 内容区加载该页
