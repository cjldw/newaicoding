# R22.F4:修复 BUG-088 需求详情页「创建开发/测试任务」指向不存在路由

- **状态**:⬜
- **关联 BUG**:BUG-088(用户报障「创建开发任务接口失败」,抓包 GET /api/tasks/create 404)
- **根因**:RequirementDetail approved 态的「创建开发任务/创建测试任务」按钮 `navigate('/tasks/create?type=x')`——该路由无页面、无注册。项目里实际存在且同文件已 import 的 `pages/tasks/TaskCreateDialog`(props: reqId/type/open/onClose/onSuccess),release 按钮早已用同款弹窗,唯 dev/test 两按钮错写成导航
- **修复方案**:两按钮改 `setCreateTaskType('dev'|'test')` + 渲染 `<TaskCreateDialog reqId={reqId} type={createTaskType} onSuccess→navigate(/tasks/{id})>`(与 release 完全同款);曾误改 manage 版 TaskCreateDialog 加预填 props,已 git checkout 撤销
- **涉及文件**:`frontend/src/pages/requirements/RequirementDetail.tsx`
- **测试验证逻辑**:tsc/build 零错;approved 需求详情页点「创建开发任务」→ 弹窗(reqId/type 预置)→ 提交 POST /requirements/{req_id}/tasks(R4 生产链路)→ 跳任务详情
- **完成判据**:用户浏览器复验创建开发任务成功
- **备注**:无独立 /tasks/create 页面属接线缺口(同 BUG-018 断链模式);如需独立创建页另立需求
