# R28.F3:修复 BUG-087 GitLab Token 绑定 405(前端 POST vs 后端 PUT 方法错位)

- **状态**:⬜
- **关联 BUG**:BUG-087(用户报障「接口绑定失败」,附 fetch 抓包:POST /api/users/me/gitlab-token)
- **根因**:后端路由是 `PUT /api/users/me/gitlab-token`(users.py:121,R1 起即 PUT),前端 `bindGitLabToken` 用 `api.post` → 每次 **405 Method Not Allowed**,绑定永远失败。token 本身有效:对 gitlab.zhanqirsj.com 与 47.111.69.64 实测均 200 返回 luowen 档案。GET 查状态/DELETE 解绑方法都配对,唯绑定错位
- **修复方案**:`frontend/src/api/users.ts` bindGitLabToken `api.post` → `api.put`(单行)
- **涉及文件**:`frontend/src/api/users.ts`
- **测试验证逻辑**:tsc/build 零错;真机 PUT 绑定有效 token → code=0 + users.gitlab_token_encrypted 落库 + GET status 为已绑定
- **完成判据**:用户在 /settings/gitlab-token 重新绑定成功(或真机 API 实证绑定落库)
- **备注**:R28.F2 编号已被 2026-09 头像修复(BUG-UI-072)占用,本修复顺延 F3
