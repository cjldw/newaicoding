# R5.F2 — 修复 BUG-069:AI 对话长消息流式输出一段后内容消失

> 来源:rd-fix 第 36 轮(2026-09-29)用户实测报障
> 关联 BUG:BUG-069(主)/ BUG-067 ①(stderr 吞错,F4 协同收口)
> 分析底稿:../.scratch/fix-analysis.md § 第 36 轮

## 描述(即 bug)

AI 对话发送「项目需要登录加上图形验证码」后,AI 流式输出了一段内容,随后消息内容又消失(长消息场景表现为「没有返回」)。用户疑点为「上次加的思考过程改坏了」——**已排除**:R35 思考过程功能未实现(DEVPLAN ⬜,代码零 thinking 引用),系 R32 流式链路既有缺陷。

## 实现要点(根因 + 修复方案)

### 根因链(四层共因,任一触发即现)

1. **runner result 提取失败(主因)**:`runner/container_manager.py:528-533` 仅当 CLI 发出 `{"type":"result","result":"..."}` 才赋值;`:572-578` 兜底取 `lines[-1]`——长消息/中途出错场景 CLI 不发 result 事件时,lines[-1] 是最后一个 `content_block_delta` 行,解析出非结果内容或残缺
2. **报错不可回溯**:`container_manager.py:497` cmd 尾 `2>/dev/null` 全吞 CLI stderr(BUG-067 ①);`runner/main.py:545-591` STREAM_TIMEOUT=120s 超时路径同样返回空 result
3. **后端空 content 落库**:`task_service.py:697-808` send_message_stream 把 `response["result"]` 直接落 `TaskMessage.content`,空串照落
4. **前端清空气泡被覆盖**:`TaskChat.tsx:418-447` handleSend `onSuccess` 立即 `setStreamText('')`,react-query refetch 用 DB 空 content 渲染空 assistant 气泡 = 「输出一段后消失」

### 修复方案(最小改动,四层分进)

- **F1 runner 层(主修复)**:`container_manager.py` `claude_prompt_stream` 读循环累积 textDelta 文本;finalize 优先级:**显式 result 事件 > 累积文本 > lines[-1] 兜底**。零行降级(R32.F8)保持不动,本项是其之外的第二道兜底(有行但无 result 事件路径)
- **F2 后端层**:`task_service.py` send_message_stream 落库前:content 空且 stream 期间收到过 delta → 用 delta 累积兜底;仍空则落 `"[AI 回复执行中断,未获取到回复内容,请重试]"` 占位 + error_message 记录,不再静默落空串
- **F3 前端层**:`TaskChat.tsx` onSuccess 不立即清 streamText——POST 返回后等 messages refetch 完成,新 assistant 消息 content 非空才清空(或流式气泡与 DB 消息二选一渲染,避免闪空)
- **F4 可观测性(BUG-067 ① 协同收口)**:去 `2>/dev/null`,stderr 捕获落 runner 日志并随 result/error 附带尾部(截断,如末 2000 字符),CLI 报错可回溯

## 测试验证逻辑

### 单元测试(QA Red → Green)

1. **runner**(runner/tests):模拟流式输出 N 行 `content_block_delta` + **无 result 事件** → `claude_prompt_stream` 返回 result=累积文本(修复前:返回 lines[-1] 解析垃圾/空,Red);② 模拟显式 result 事件 → 行为不变(回归);③ 零行 → 仍走 R32.F8 零行降级(回归);④ stderr 捕获:模拟 CLI 报错,断言 stderr 进返回值/日志
2. **backend**(backend/tests):① runner 响应 result 空但带累积文本 → 落库 content=累积文本;② 双空 → 落占位文案 + error_message,而非空串;③ 正常路径 content=result 不变(回归)
3. **frontend**:`npx tsc --noEmit` 零错误 + `npx vite build` 通过;代码级断言 onSuccess 清空时序(refetch 完成且 content 非空才清)

### 真机回归判据

- **复现消息**:「项目需要登录加上图形验证码」(用户原话)
- **期望**:assistant 消息稳定呈现不消失;task_messages.content 非空
- 判据 1:正常短消息 content = CLI result 文本(行为不变)
- 判据 2:长消息(>120s 超时)前端呈现已生成部分(F1 兜底)或明确错误态,不静默消失
- 判据 3:CLI 中途出错 → stderr 进 runner 日志可回溯(F4)
- 判据 4:流式平滑(R32.F7)不受影响
