> 关联:BUG-009(建仓/拉码无权限)的真正根因;BUG-010(测试连接 401 提示)的上游

## 描述(bug)

curl 实证(gitlab.zhanqirsj.com,GitLab 11.7.0,http-only):
- `PRIVATE-TOKEN: <PAT>` → 200
- `Authorization: Bearer <PAT>` → 401

`gitlab_service.py` 两处用 Bearer 调 GitLab → 全部 bot 调用(test-connection/建仓/成员同步/分支)与个人 token 验证恒 401。

## 实现要点

`backend/app/services/gitlab_service.py`:
1. L60 `verify_gitlab_token`:`headers = {"Authorization": f"Bearer {gitlab_token}"}` → `{"PRIVATE-TOKEN": gitlab_token}`
2. L113 `_bot_headers`:`return {"PRIVATE-TOKEN": bot_token}`(所有 bot_* 调用自动修复)

注释留痕:GitLab PAT 仅认 PRIVATE-TOKEN;Bearer 仅用于 OAuth token(平台 V1 不用)。

3. 波及:成员同步/建仓等 bot_* 调用头自动纠正(静态核对共用 `_bot_headers`)
