- **PRD 引用**(边界定义 + 验收标准 + 异常场景摘录,源 PRD 增量9 R38 节):
  - 做什么:Diff Tab 口径开关(默认「全部改动」);开关全局联动 Diff chips、diff 正文、FileTree「变更文件」Tab;「仅未提交」空态区分文案 + 一键切回;后端 changes/diff 两端点新增 scope 语义
  - 不做什么:不做按文件勾选/暂存区管理;不做历史版本对比;不改变任务结束自动 commit+push 链;不做第三口径
  - 验收标准:① 开关切换后 chips 与正文同步换口径(FileTree Tab 同步)② AI commit 一笔后 all 口径仍含、head 口径不再含且空态文案正确 ③ 默认进入为「全部改动」口径(现状不变)
  - 异常场景:head 口径下 AI 中途 commit 的改动不可见(预期,all 可见);all 口径基线分支不存在保留 `|| HEAD` 兜底;容器不可达 9001 + R4.F8 错误条重试(现状)
