## PRD 引用

### 边界定义

- **做什么**:
  - **手机号+密码注册/登录**、找回密码(V2 短信验证码)、登出、修改本人密码/昵称/头像
  - **GitLab 个人 token 绑定/解绑/重新绑定**:任务执行(clone/pull/push/commit)使用用户自己的 token,确保 GitLab 侧操作可追溯到人
- **不做什么**:第三方 OAuth、SSO、邮箱验证、GitLab OAuth(仅用 personal access token);**V1 不接短信服务商**(预留字段与接口,短信功能 V2 再做)

### 字段定义

(User 表)
| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|---|---|---|---|---|---|

### 交互规则

| 场景/条件 | 行为/规则 | 结果/去向 |
|---|---|---|
| 注册重名 | 拒绝并提示字段 | 停留注册页 |
| 密码错 5 次 | 锁 10 分钟 | 返回倒计时 |
| **找回密码(V2)** | **短信验证码**(6 位数字,10 分钟有效) | 重置页 |
| 登录成功 | JWT(access 2h + refresh 7d,均携带 token_version,见 R19/D17) | Dashboard(R21,`/`;项目列表经左侧导航可达) |
| 绑定 GitLab token | 用户粘贴 token → 平台调 `GET /user` 验证 → 校验 scope 含 `read_repository`+`write_repository` → 保存 username 与 scopes | 绑定成功 |
| token scope 不足 | 提示具体缺失的 scope,拒绝绑定 | 停留绑定页 |
| token 失效(任务执行 401) | 任务标记 failed,引导用户到个人设置重新绑定 | 任务列表提示 |
| 解绑 | 清空 gitlab_* 字段;**进行中的任务不受影响**(已在容器内的 token 仍可用到任务结束) | |

### 异常与边界场景

- **短信服务不可用(V2)** → 找回密码降级"联系管理员"
- 多处登录允许(V1 不做单点踢出)
- phone 不可改
- token 加密密钥:平台级 KMS/环境变量,V1 用单 key;若 key 泄露需全量重新绑定
- 未绑定 token 的用户:仅可浏览(viewer 角色不绑也能看);editor/owner 创建任务前**强制绑定**(R12)

### 验收标准

1. 注册-登录-登出闭环
2. 5 次错误触发锁定
3. **找回密码短信可达(V2),验证码一次性**
4. 密码无明文落盘/日志
5. GitLab token 绑定/解绑/重绑可用
6. scope 不足时给出明确错误
7. token 失效时任务 failed 并引导重绑
8. token 不明文出现在接口/日志/前端

### 接口契约

**接口契约** 总览——**响应结构**统一外层 `{"code": 0, "data": ..., "message": "ok"}`(错误时 `code` 为业务错误码、`message` 为提示文案);字段级结构以下方各接口小节的请求/响应示例为准:

| 接口范围 | 响应结构约定 |
|---|---|
| 本需求点全部接口(下方小节逐一列出) | 统一外层 `{code, data, message}`;分页接口 `data` 含 `{items, total}` |

#### 1. 注册

- **路径**:`POST /api/auth/register`
- **鉴权**:无
- **请求**:
  ```json
  {
    "phone": "string(11位,合法手机号)",
    "password": "string(≥8位,含字母+数字)",
    "invitation_token": "string(可选,邀请制)"
  }
  ```
- **请求校验**(zod schema):
  ```typescript
  const registerSchema = z.object({
    phone: z.string().regex(/^1[3-9]\d{9}$/, "手机号格式错误"),
    password: z.string().min(8, "密码至少8位").regex(/^(?=.*[a-zA-Z])(?=.*\d)/, "密码需包含字母和数字"),
    invitation_token: z.string().optional()
  })
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": {
      "user_id": "uuid",
      "phone": "138****1234"
    },
    "message": "注册成功"
  }
  ```
- **错误码**:
  - `1001`: phone 已存在
  - `1003`: 密码不符合规则
  - `1004`: invitation_token 无效(邀请制)

#### 2. 登录

- **路径**:`POST /api/auth/login`
- **鉴权**:无
- **请求**:
  ```json
  {
    "phone": "string(11位)",
    "password": "string"
  }
  ```
- **请求校验**(zod schema):
  ```typescript
  const loginSchema = z.object({
    phone: z.string().regex(/^1[3-9]\d{9}$/, "手机号格式错误"),
    password: z.string().min(1, "请输入密码")
  })
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": {
      "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "user": {
        "user_id": "uuid",
        "phone": "138****1234",
        "nickname": "string",
        "avatar_url": "string"
      }
    },
    "message": "登录成功"
  }
  ```
- **响应字段说明**:
  | 字段 | 类型 | 说明 |
  |---|---|---|
  | access_token | string | JWT,2h 有效期,用于 API 鉴权 |
  | refresh_token | string | JWT,7d 有效期,用于刷新 access_token |
  | user.user_id | string(uuid) | 用户对外 id |
  | user.phone | string | 手机号(打码,前 3 位 + `****` + 后 4 位) |
  | user.nickname | string | 显示名 |
  | user.avatar_url | string | 头像 URL |
- **错误码**:
  | 错误码 | 场景 | 响应示例 |
  |---|---|---|
  | 1005 | 手机号或密码错误 | `{"code": 1005, "message": "手机号或密码错误", "data": null}` |
  | 1006 | 账号锁定 | `{"code": 1006, "message": "账号已锁定,请 10 分钟后重试", "data": {"remaining_seconds": 600}}` |
  | 1007 | 账号禁用 | `{"code": 1007, "message": "账号已被禁用,请联系管理员", "data": null}` |

### 服务端行为规格

#### 密码哈希

- 算法:bcrypt(cost=12)
- 库:`passlib[bcrypt]`
- 存储:`password_hash` 字段(VARCHAR(255))
- 校验:`passlib.verify(password, password_hash)`

#### JWT

- 算法:HS256
- 密钥:环境变量 `JWT_SECRET_KEY`
- access token:2h 有效期,载荷 `{"user_id": "...", "exp": ...}`
- refresh token:7d 有效期,载荷 `{"user_id": "...", "type": "refresh", "exp": ...}`
- 库:`pyjwt`

#### AES-GCM 加密

- 算法:AES-256-GCM
- 密钥:环境变量 `PLATFORM_SECRET_KEY`(32 字节,base64 编码)
- 库:`cryptography`
- 加密字段:`gitlab_token_encrypted`
- 格式:`base64(nonce + ciphertext + tag)`

#### GitLab token 验证

- 调 GitLab API:`GET {gitlab_instance_url}/api/v4/user`
- 请求头:`PRIVATE-TOKEN: {user_token}`
- 校验:
  - 200 → token 有效,解析 `username` 与 `scopes`
  - 401 → token 无效,返回 `1012`
  - scope 不含 `read_repository` 或 `write_repository` → 返回 `1013`

#### 手机号打码

- 接口返回时,`phone` 字段打码:前 3 位 + `****` + 后 4 位
- 例:`13812341234` → `138****1234`

#### 找回密码(V2)

- 短信服务:阿里云短信/腾讯云短信(V2 选型)
- 短信内容:`您的验证码是 {code},10 分钟内有效`
- 验证码存储:Redis(或 MySQL 临时表),key=`sms_code:{phone}:{scene}`,value=code,TTL=10min
- 频率限制:同手机号 1 分钟内只能发 1 次

### 异常场景

1. ✅ 注册重名:返回 `1001`(phone 已存在)
2. ✅ 登录密码错误:返回 `1005`(手机号或密码错误)
3. ✅ 登录密码错 5 次:返回 `1006`(账号锁定,含剩余秒数)

7. ✅ GitLab token scope 不足:返回 `1013`(提示缺 read_repository/write_repository)
8. ✅ 短信服务不可用(V2):找回密码降级"联系管理员"
