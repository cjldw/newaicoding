## PRD 引用

### 边界定义

- **做什么**:
  - 账号+密码注册/登录、找回密码(邮件)、登出、修改本人密码/昵称/头像
  - **GitLab 个人 token 绑定/解绑/重新绑定**:任务执行(clone/pull/push/commit)使用用户自己的 token,确保 GitLab 侧操作可追溯到人
- **不做什么**:第三方 OAuth、SSO、手机号验证、GitLab OAuth(仅用 personal access token)

### 字段定义

(User 表)
| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|---|---|---|---|---|---|
| username | string(32) | 是 | - | 全局唯一,字母数字下划线,3-32 | 登录名 |
| email | string(255) | 是 | - | 合法邮箱,全局唯一 | 找回密码 |
| password | string | 是 | - | ≥8 位含字母+数字,bcrypt 存储 | 不明文 |
| nickname | string(32) | 否 | =username | - | |
| avatar_url | string(255) | 否 | 默认头像 | URL | |
| status | enum | 是 | active | active/disabled | |
| gitlab_username | string(64) | 否 | null | - | GitLab 上的用户名(绑定时从 GitLab 拉取) |
| gitlab_token_encrypted | string | 否 | null | AES-GCM 加密 | personal access token,接口永不回显完整 |
| gitlab_token_scopes | json | 否 | null | - | 用户授权的 scope 列表(read_repository/write_repository/api) |

### 交互规则

| 场景/条件 | 行为/规则 | 结果/去向 |
|---|---|---|
| 注册重名 | 拒绝并提示字段 | 停留注册页 |
| 密码错 5 次 | 锁 10 分钟 | 返回倒计时 |
| 找回密码 | 邮件含一次性 token,30min 有效 | 重置页 |
| 登录成功 | JWT(access 2h + refresh 7d) | 项目列表 |
| 绑定 GitLab token | 用户粘贴 token → 平台调 `GET /user` 验证 → 校验 scope 含 `read_repository`+`write_repository` → 保存 username 与 scopes | 绑定成功 |
| token scope 不足 | 提示具体缺失的 scope,拒绝绑定 | 停留绑定页 |
| token 失效(任务执行 401) | 任务标记 failed,引导用户到个人设置重新绑定 | 任务列表提示 |
| 解绑 | 清空 gitlab_* 字段;**进行中的任务不受影响**(已在容器内的 token 仍可用到任务结束) | |

### 异常与边界场景

- 邮箱服务不可用 → 找回密码降级"联系管理员"
- 多处登录允许(V1 不做单点踢出)
- username 不可改,email 可改
- token 加密密钥:平台级 KMS/环境变量,V1 用单 key;若 key 泄露需全量重新绑定
- 未绑定 token 的用户:仅可浏览(viewer 角色不绑也能看);editor/owner 创建任务前**强制绑定**(R12)

### 验收标准

1. 注册-登录-登出闭环
2. 5 次错误触发锁定
3. 找回密码邮件可达,token 一次性
4. 密码无明文落盘/日志
5. GitLab token 绑定/解绑/重绑可用
6. scope 不足时给出明确错误
7. token 失效时任务 failed 并引导重绑
8. token 不明文出现在接口/日志/前端

### 接口契约

#### 1. 注册

- **路径**:`POST /api/auth/register`
- **鉴权**:无
- **请求**:
  ```json
  {
    "username": "string(3-32,字母数字下划线)",
    "email": "string(合法邮箱)",
    "password": "string(≥8位,含字母+数字)",
    "invitation_token": "string(可选,邀请制)"
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": {
      "user_id": "uuid",
      "username": "string",
      "email": "string"
    },
    "message": "注册成功"
  }
  ```
- **错误码**:
  - `1001`: username 已存在
  - `1002`: email 已存在
  - `1003`: 密码不符合规则
  - `1004`: invitation_token 无效(邀请制)

#### 2. 登录

- **路径**:`POST /api/auth/login`
- **鉴权**:无
- **请求**:
  ```json
  {
    "username": "string",
    "password": "string"
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": {
      "access_token": "string(JWT,2h)",
      "refresh_token": "string(JWT,7d)",
      "user": {
        "user_id": "uuid",
        "username": "string",
        "nickname": "string",
        "avatar_url": "string"
      }
    },
    "message": "登录成功"
  }
  ```
- **错误码**:
  - `1005`: 用户名或密码错误
  - `1006`: 账号锁定(密码错 5 次,锁 10 分钟,返回剩余秒数)
  - `1007`: 账号禁用

#### 3. 刷新 token

- **路径**:`POST /api/auth/refresh`
- **鉴权**:无(但需 refresh_token)
- **请求**:
  ```json
  {
    "refresh_token": "string"
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": {
      "access_token": "string(JWT,2h)"
    },
    "message": "ok"
  }
  ```
- **错误码**:
  - `1008`: refresh_token 无效或过期

#### 4. 找回密码

- **路径**:`POST /api/auth/forgot-password`
- **鉴权**:无
- **请求**:
  ```json
  {
    "email": "string"
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "message": "重置密码邮件已发送,请查收"
  }
  ```
- **错误码**:
  - `1009`: 邮箱不存在(不返回,统一返回"已发送",防枚举)

#### 5. 重置密码

- **路径**:`POST /api/auth/reset-password`
- **鉴权**:无(但需邮件 token)
- **请求**:
  ```json
  {
    "token": "string(邮件里的一次性 token,30min 有效)",
    "new_password": "string(≥8位,含字母+数字)"
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "message": "密码重置成功,请重新登录"
  }
  ```
- **错误码**:
  - `1010`: token 无效或过期
  - `1003`: 密码不符合规则

#### 6. 获取当前用户信息

- **路径**:`GET /api/users/me`
- **鉴权**:JWT
- **响应**:
  ```json
  {
    "code": 0,
    "data": {
      "user_id": "uuid",
      "username": "string",
      "email": "string",
      "nickname": "string",
      "avatar_url": "string",
      "gitlab_username": "string|null",
      "gitlab_token_bound": "bool",
      "gitlab_token_scopes": ["read_repository", "write_repository"],
      "gitlab_token_bound_at": "datetime|null"
    },
    "message": "ok"
  }
  ```

#### 7. 更新个人信息

- **路径**:`PATCH /api/users/me`
- **鉴权**:JWT
- **请求**:
  ```json
  {
    "nickname": "string(可选)",
    "avatar_url": "string(可选)",
    "email": "string(可选,改邮箱需重新验证)"
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": { /* 同 GET /api/users/me */ },
    "message": "更新成功"
  }
  ```
- **错误码**:
  - `1002`: email 已存在

#### 8. 绑定 GitLab token

- **路径**:`PUT /api/users/me/gitlab-token`
- **鉴权**:JWT
- **请求**:
  ```json
  {
    "gitlab_token": "string(GitLab personal access token)"
  }
  ```
- **响应**:
  ```json
  {
    "code": 0,
    "data": {
      "gitlab_username": "string",
      "gitlab_token_scopes": ["read_repository", "write_repository"],
      "gitlab_token_bound_at": "datetime"
    },
    "message": "绑定成功"
  }
  ```
- **错误码**:
  - `1011`: token 无效(GitLab API 401)
  - `1012`: scope 不足(缺 `read_repository` 或 `write_repository`)

#### 9. 解绑 GitLab token

- **路径**:`DELETE /api/users/me/gitlab-token`
- **鉴权**:JWT
- **响应**:
  ```json
  {
    "code": 0,
    "message": "解绑成功"
  }
  ```

### 权限矩阵

| 操作 | 未登录 | 已登录(未绑 token) | 已登录(已绑 token) |
|---|---|---|---|
| 注册 | ✅ | - | - |
| 登录 | ✅ | - | - |
| 找回密码 | ✅ | - | - |
| 查看个人信息 | ❌ | ✅ | ✅ |
| 更新个人信息 | ❌ | ✅ | ✅ |
| 绑定/解绑 GitLab token | ❌ | ✅ | ✅ |
| 创建任务(R4) | ❌ | ❌ | ✅(需校验 repo 权限) |

### 服务端行为规格

#### 密码哈希

- 算法:bcrypt(cost=12)
- 库:`passlib[bcrypt]`
- 存储:`password_hash` 字段(VARCHAR(255))
- 校验:`passlib.verify(password, password_hash)`

#### JWT

- 算法:HS256
- 密钥:环境变量 `JWT_SECRET_KEY`
- access token:2h 有效期,载荷 `{"user_id": "...", "exp": ...}`
- refresh token:7d 有效期,载荷 `{"user_id": "...", "type": "refresh", "exp": ...}`
- 库:`pyjwt`

#### AES-GCM 加密

- 算法:AES-256-GCM
- 密钥:环境变量 `PLATFORM_SECRET_KEY`(32 字节,base64 编码)
- 库:`cryptography`
- 加密字段:`gitlab_token_encrypted`
- 格式:`base64(nonce + ciphertext + tag)`

#### GitLab token 验证

- 调 GitLab API:`GET {gitlab_instance_url}/api/v4/user`
- 请求头:`PRIVATE-TOKEN: {user_token}`
- 校验:
  - 200 → token 有效,解析 `username` 与 `scopes`
  - 401 → token 无效,返回 `1011`
  - scope 不含 `read_repository` 或 `write_repository` → 返回 `1012`

#### 找回密码邮件

- 邮件服务:SMTP(aiosmtplib)
- 邮件内容:含一次性 token(uuid,30min 有效),链接 `https://platform.example.com/reset-password?token=xxx`
- token 存储:Redis(或 MySQL 临时表),key=`reset_password:{token}`,value=user_id,TTL=30min

### 页面交互流程

#### 登录流程

1. 用户输入用户名+密码 → 点"登录"
2. 前端调 `POST /api/auth/login`
3. 成功 → 存 JWT 到 Zustand `authStore` → 跳转 `/projects`
4. 失败 → 显示错误提示(Alert,error)→ 留在登录页

#### 注册流程

1. 用户填表 → 点"注册"
2. 前端校验:zod schema(username/email/password 格式;两次密码一致)
3. 调 `POST /api/auth/register`
4. 成功 → 提示"注册成功,请登录" → 3s 后跳转 `/login`
5. 失败 → 显示错误提示

#### 找回密码流程

1. 用户输入邮箱 → 点"发送重置邮件"
2. 调 `POST /api/auth/forgot-password`
3. 成功 → 提示"邮件已发送"
4. 用户收邮件 → 点链接 → 跳转 `/reset-password?token=xxx`
5. 用户输入新密码 → 点"重置密码"
6. 调 `POST /api/auth/reset-password`
7. 成功 → 提示"重置成功" → 跳转 `/login`

#### GitLab token 绑定流程

1. 用户进入 `/settings/gitlab-token`
2. 未绑定 → 显示输入框 + "绑定"按钮
3. 用户粘贴 token → 点"绑定"
4. 调 `PUT /api/users/me/gitlab-token`
5. 成功 → 显示已绑定状态(GitLab 用户名/scope/绑定时间)
6. 失败 → 显示错误提示(token 无效/scope 不足)

## 完成判据

### 功能

1. ✅ 用户能注册(用户名/邮箱/密码/邀请码)
2. ✅ 用户能登录(用户名+密码,返回 JWT)
3. ✅ 用户能找回密码(邮件含一次性 token,30min 有效)
4. ✅ 用户能重置密码(用邮件 token)
5. ✅ 用户能登出(清除 JWT)
6. ✅ 用户能查看/更新个人信息(昵称/头像/邮箱)
7. ✅ 用户能绑定 GitLab token(验证 token 有效 + scope 含 read_repository+write_repository)
8. ✅ 用户能解绑 GitLab token
9. ✅ 密码错 5 次锁定 10 分钟
10. ✅ token 不明文出现在接口/日志/前端

### 异常场景

1. ✅ 注册重名:返回 `1001`(username 已存在)/ `1002`(email 已存在)
2. ✅ 登录密码错误:返回 `1005`(用户名或密码错误)
3. ✅ 登录密码错 5 次:返回 `1006`(账号锁定,含剩余秒数)
4. ✅ 找回密码邮箱不存在:统一返回"已发送"(防枚举)
5. ✅ 重置密码 token 无效/过期:返回 `1010`
6. ✅ GitLab token 无效(401):返回 `1011`
7. ✅ GitLab token scope 不足:返回 `1012`(提示缺 read_repository/write_repository)
8. ✅ 邮箱服务不可用:找回密码降级"联系管理员"

### UI

1. ✅ 登录页/注册页/找回密码页/重置密码页:居中卡片(400px),垂直居中
