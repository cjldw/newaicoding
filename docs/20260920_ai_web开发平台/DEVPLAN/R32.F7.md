# R32.F7:修复 BUG-059 流式体验(上游非流式时打字机平滑下发)

> 状态:🔄 进行中(代码完成+探针实证;用户浏览器复验后 verified)
> 模块:M5/M4(后端 task_service 广播层)
> 关联:BUG-059

## 根因

上游网关非流式(BUG-058 实证 span=0.00s)→ 平台收到的 126 个 chat_delta 挤在
0.14s 内瞬达 → 前端一瞬间渲染完,视觉等同同步整段输出。

## 修复

广播层打字机平滑器 `_broadcast_delta_smooth`:单帧拆分(≤16 字符)+ 帧间隔下限
(30ms);增量到达间隔大于下限零延迟直通(真流式网关零改动自适应);节奏状态
同一轮对话共享(delta_state)。

## 验证

- pytest 8/8(拆分/保序/节奏/直通 + registry/映射回归)
- 真机:200 词 → 203 帧跨度 7.89s,均匀分布,chat_done 收尾
