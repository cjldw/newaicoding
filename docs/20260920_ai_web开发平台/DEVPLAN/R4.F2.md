# R4.F2 — 工作台缺陷批修复 + 四项 UI 增强(BUG-UI-065)

> 来源:用户实测反馈 2026-09-23("terminal 不行,编辑器底部太贴边,diff 不行,对话框不行")+
> 用户选定 UI 增强:编辑器状态栏 / 终端高度可拖拽 / 左右栏宽可拖拽 / 任务头状态 chips
> 状态:✅ fixed(2026-09-23;tsc 零错 + build 9.47s;verified 待浏览器)

## 根因(两路探查实证)

1. **terminal 不行**:`vite.config.ts` 只代理 `/api`,**`/ws` 前缀无代理** → 终端/文件 watcher WS 全部连到 5173 死角;另 handleClose 双 setTabs 相互覆盖(tab 关不掉)
2. **diff 不行**:查看 Diff 按钮不设 diffPath → 恒落占位符;currentDiff 空匹配渲染双空 DiffViewer
3. **对话框不行**:前端链路正常;发送后同步执行(最长 600s)无任何 pending 反馈,观感即"不行"
4. **编辑器底部贴边**:布局正确但无底部缓冲/信息栏

## 修复与增强(改动清单)

| 文件 | 改动 |
|---|---|
| vite.config.ts | proxy 加 `'/ws'`(ws:true + changeOrigin,query token 保留)——**dev server 需重启生效** |
| TerminalPanel.tsx | handleClose 重写(单次 filter + activeId 归位) |
| TaskDetail.tsx | 查看 Diff 自动取首个变更文件;currentDiff 无匹配→空态;任务头 chips(分支/容器/Runner,chip 类对齐 vp);左栏/右栏宽度 + 终端条高度 useDragSash 拖拽(含 3 条 sash);工作区 p-2;编辑器底部状态栏(path/保存态) |
| hooks/useDragSash.ts(新) | 通用拖拽 hook(clamp + document 级监听,松手解绑) |
| TaskChat.tsx | 发送 pending:按钮转圈/禁用 + "AI 处理中…"提示条 |
