# PRD:MCP/Skills 系统级已安装列表(容器探测)

> 创建日期:2026-09-27
> 状态:**已确认**(2026-09-27,两项边界已拍板,待确认清单为空)
> 关联:平台主 PRD R17(Skills/MCP 接入);R32(任务对话 /skills、/mcp 注入与补全)

## 背景与目标

平台对 MCP/Skills 的「配置态」(项目配置了什么)与容器内 Claude CLI 的「实际安装态」(镜像内置 + 已注入)是两回事:内置能力对用户不可见,AI 对话 `/skills`、`/mcp` 调整时候选不全。本需求新增**系统级已安装列表**——从真实容器探测 Claude 已安装的 skills 与 MCP,入库后只读展示,并合并进 AI 对话候选。

## 用户故事

1. 作为超管,我希望看到 devbox 镜像里实际内置的 skills/MCP 清单,以便掌握系统能力
2. 作为项目成员,我希望在 AI 对话 `/skills`、`/mcp` 里看到系统内置项,以便知道哪些能力开箱即用

## 需求点清单

### R1:系统级采集(临时容器探测入库)

- **描述**:从容器内探测 Claude 实际安装的 skills 与 MCP 列表入库;首次无数据时**临时启动一个 devbox 容器**执行采集后销毁;超管可手动「重新采集」
- **触发场景**:超管在平台侧点击「采集系统级列表」(首采与重新采集同一入口)
- **前置条件**:超管;devbox 镜像可用
- **边界定义**:
  - 做什么:临时容器内探测——skills=列 `/root/.claude/skills/` 下的 skill 目录名;MCP=读 `/root/.claude.json` 的 mcpServers(名称+传输类型);入库(表设计 rd-plan 定,建议单表或两表,记录 name/kind(skill|mcp)/detail/采集时间/镜像标识);容器用后即毁;采集期间加进程内锁防并发重复起容器
  - 不做什么:不在任务容器启动时自动回采;不探测项目级注入态(系统级=镜像内置,不含任务注入物);不做镜像版本 diff
- **字段定义**(采集记录):
  | 字段 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | name | string | 是 | skill 目录名 / mcp server 名 |
  | kind | enum skill/mcp | 是 | 类别 |
  | detail | JSON | 否 | MCP 传输类型/命令等探测原文;skill 可空 |
  | collected_at | datetime | 是 | 采集时间;镜像标识 rd-plan 定(镜像 tag 或容器 image 摘要) |
- **依赖**:无(容器基建已有)
- **异常与边界场景**:临时容器启动失败 → 报错可重试;容器内探测命令失败 → 返回部分结果+警告;并发点击采集 → 锁内串行;采集结果为空 → 空表入库并提示「镜像未内置」
- **验收标准**:
  1. 首采:临时容器启动→采集→销毁,列表入库可见
  2. 重新采集覆盖旧数据
  3. 采集期间二次点击被锁提示
  4. 容器启动失败给出可重试错误

### R2:系统级列表只读展示(超管区 + 项目管理页)

- **描述**:两处只读展示——① 超管侧:平台 Skills 市场/设置区与 MCP 管理区加「系统级已安装」区块(含采集按钮/采集时间);② 项目侧:项目 Skills 管理页与 MCP 管理页各加「系统级」只读 Tab/区块(标「镜像内置」),与项目配置列表并列
- **前置条件**:R1 已采集(未采集显示引导态+超管可见采集按钮)
- **边界定义**:
  - 做什么:只读列表(name/detail/采集时间);项目侧与平台侧同数据源
  - 不做什么:系统级不可增删改(只读);不做项目级启用开关(系统级天然可用)
- **字段定义**:同 R1
- **依赖**:R1
- **异常与边界场景**:未采集 → 引导态(超管见采集按钮,成员见「暂未采集」)
- **验收标准**:两处展示一致;只读无写入口

### R3:AI 对话 /skills、/mcp 候选合并系统级

- **描述**:AI 对话的 `/skills`、`/mcp` 调整功能(R32)候选数据源改为「用户/项目配置 ∪ 系统级已安装」合并,系统项标注「内置」;调整逻辑(启用/禁用项目注入)仅作用于项目配置项,系统级项只读展示
- **触发场景**:AI 对话输入 /skills 或 /mcp
- **前置条件**:R1/R2
- **边界定义**:
  - 做什么:候选列表合并去重(同名以项目配置为准);系统项带「内置」徽标,不可禁用
  - 不做什么:不改注入链本身;系统项不参与注入配置
- **依赖**:R1、R32 现有 /skills、/mcp 功能
- **异常与边界场景**:系统级未采集 → 候选仅项目配置(现状回退);同名冲突 → 项目配置覆盖展示
- **验收标准**:
  1. /skills 候选=项目配置+系统内置,内置项标注且不可调
  2. /mcp 同上
  3. 系统级未采集时行为与现状一致
