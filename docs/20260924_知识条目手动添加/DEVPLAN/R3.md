# R3:条目编辑与删除

- **状态**:⬜
- **依赖**:R2(入口在详情页)
- **模块**:M1 后端 + M2 前端

## PRD 引用

创建者可编辑自己创建的人工条目(title/type/tags/content/代码引用);**AI 条目仅可编辑标签(已确认)**,正文为归档产物不可改。删除:创建者本人 + 项目 owner/editor;平台级条目仅超管。入口在详情页。

## 接口契约

**新增** `PATCH /api/knowledge/{entry_id}`:
- 请求 `{title?, type?, tags?, content?, source_links?}`
- 鉴权与规则:
  - 人工条目(created_by=human):创建者本人(created_by_user_id 相等)或项目 owner/editor 可全字段编辑
  - AI 条目(created_by=ai):仅 tags 字段生效;携带其他字段 → 400 20013「AI 条目仅支持编辑标签」
  - 平台级条目:仅超管可编辑
- 审计:沿用现有审计体系记录操作人

**新增** `DELETE /api/knowledge/{entry_id}`:
- 鉴权:项目级=创建者本人或 owner/editor;平台级=仅超管
- 物理删除(条目无版本管理,PRD 范围外);响应 success

## 数据模型变更

- `knowledge_entries` 新增列 `created_by_user_id CHAR(36) NULL`(判定「创建者本人」;历史行 NULL → 仅 owner/editor/超管可编删,回落安全)
- 迁移:`e8f4a2c6b9d1_r32_knowledge_author.py`,down_revision="c7d3e9b5a2f4";`create_entry` 写入 operator.user_id
- SQL 全文进 DEPLOY.md
