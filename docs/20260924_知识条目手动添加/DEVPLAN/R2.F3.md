# R2.F3:修复页面内容滚动时与顶栏重叠(BUG-KB-002)

- **状态**:✅(verified)
- **根因**(分析实证):路由内容无滚动容器——滚动发生在 body 上,长页搜索框滚入半透明 sticky 顶栏下方 27.7px(截图实证);工作区并发流的 `.main{overflow:hidden}` 掩盖现象但改为裁切内容,不可取

## 实现要点

MainLayout.tsx:Outlet 外包一层 `.route-scroll`;globals.css 加 `.route-scroll{flex:1;min-height:0;overflow-y:auto}`。**不动并发流未提交的 `.main{overflow:hidden}`**(他股 WIP,共存不冲突——内层滚动容器独立工作)。

## 测试验证逻辑

1. /knowledge 长列表滚动到底:搜索框不被顶栏遮盖(浏览器截图对比)
2. 四维管理/任务详情等工作台页回归:布局不塌(它们有自己的滚动体系)
3. tsc 零错误
