# R1.F1:平台页创建成功后的去向引导(修 BUG-KB-001)

- **状态**:✅(真机回归 11/11 断言通过,verified;截图 report/fix-r1f1/)
- **关联 BUG**:BUG-KB-001(UX 断裂;后端无 bug,API 实证条目已在项目列表 total=8 第 5 条)

## 描述

平台知识库页(/knowledge)创建条目(选归属项目)成功后,仅弹纯文本 toast(useToast 不支持动作链接),且失效 platform-knowledge 属无效动作(条目是项目级,平台列表按设计不显示)。用户找不到刚创建的记录。

## 实现要点

仅改 frontend/src/pages/knowledge/KnowledgeBase.tsx(平台 scope 分支):
1. 创建成功后 Dialog 进**成功态**:CheckCircle 图标 +「创建成功」+ 说明文字「条目已创建到项目「{项目名}」知识库;平台级条目由项目 owner 提升产生」+ 两个按钮:「前往项目知识库查看」(navigate(`/projects/{targetPid}/knowledge`))与「继续创建」(重置表单留在 Dialog)/「关闭」
2. 删除创建成功回调里的 platform-knowledge invalidate(无效动作);项目 scope 行为不变(成功关 Dialog 刷新列表)
3. 项目 scope 不受影响:成功仍直接关 Dialog + toast

## 测试验证逻辑

1. 复现步骤回归:平台页创建 → Dialog 出现成功态 → 点「前往项目知识库查看」落到 /projects/{pid}/knowledge 且列表可见新条目
2. 项目页创建 → 行为与修复前一致(关 Dialog + toast + 列表刷新)
3. `npx tsc -b --noEmit` 零错误
