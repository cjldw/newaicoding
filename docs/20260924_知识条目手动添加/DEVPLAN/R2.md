## 接口契约

**收紧** `GET /api/knowledge/{entry_id}`(api/knowledge.py:90,现仅登录即可):
- 项目级条目:要求该项目 viewer;平台级:登录即可(全员可见,沿用 PRD 权限口径)
- 非成员访问项目级 → 403

**新增** `GET /api/knowledge/{entry_id}/code?path={path}`:
- 用途:详情页按路径拉代码(逐路径请求,失败互不影响)
- 实现:读条目 source_links 的 code 对象 → 按 repo_id 查 ProjectRepo 取 gitlab_repo_id → `gitlab_service.bot_get_file`(file_service.project_file_content 只取 role=main 主仓,此处需按指定 repo 故直连 bot_get_file,base64→utf-8、二进制拒绝;**单文件不截断,全量返回**)
- path 目录时:**递归拉全**——`bot_get_tree` recursive 取全树,目录下所有文本文件逐个 `bot_get_file` 拉内容,组装成树状结构返回;二进制文件(按扩展名/内容探测)只列节点不拉内容
- **服务端本地缓存**:进程内缓存(如 functools TTL cache 或服务层 dict + 过期),键 `{repo_id}:{branch}:{path}`,TTL 5 分钟;「重新拉取」按钮带 `?refresh=1` 跳过缓存
- 响应 `{path, kind:file|dir, content?, tree?: [{path, kind, size, content?, children?}], size}`;404 → code 20012「代码来源不可达」;repo 已解绑(ProjectRepo 不存在)→ 20012 同码
- 防护:目录递归总文件数上限 200(超出截断并返回 `partial:true` 提示),单目录响应体上限 10MB
- 鉴权:同 detail(项目级 viewer / 平台级登录)

```
├─ .page-head:←返回 | 类型徽章+标题 | 状态徽章 | .acts(发布/提升/编辑/删除,按权限显示)

```

## 控件联动

- 点「重新拉取」→ 单块重新请求 code 接口 → 成功替换内容 / 失败显示错误占位
- 点「发布」→ 确认 → 接口成功 → 徽章 draft→published,按钮消失
- 点「提升到平台级」→ 确认(文案提示提升后不可撤回项目级)→ 成功 → 跳转 /knowledge 平台库
