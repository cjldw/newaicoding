# PRD:知识条目手动添加与 Markdown 查看

> 创建日期:2026-09-24
> 状态:**已确认**(2026-09-25,待确认清单已空)
> 关联:平台主 PRD R14(`docs/20260920_ai_web开发平台/PRD.md`:828-873),本需求是其「用户手动新增知识」的补全与增强

## 背景与现状

平台已有 R14 知识条目体系(`knowledge_entries` 表 + 项目/平台两级 + AI 归档提取),且「手动新增」已有最小实现(POST /projects/{pid}/knowledge + 新建 Dialog),但存在明显缺口:

1. 新建 Dialog 只有 type/title/content/tags 四字段,**无法关联已有代码**(仓库/分支/路径)
2. 条目**没有详情页**,列表卡片摘要恒为空(后端 brief 不返回 content),ArchivePage 的「查看」按钮是空实现
3. 条目内容按 Markdown 存储但**查看侧无任何渲染**
4. 条目**无编辑/删除接口**
5. 平台级无手动直建入口(只能项目级建后 owner promote)

## 需求点

### R1:手动添加知识条目 —— 两种类型

项目内任意成员可手动创建知识条目,分两种类型:

**类型 A:关联已有代码(代码引用型)**
- 创建时选择:项目绑定的 GitLab 仓库 + 分支 + 目录/文件路径(同库同分支多路径,上限 10 个)
- 条目保存代码**引用信息**(repo/branch/paths),查看时实时从 GitLab 拉取代码内容渲染(带语法高亮)
- 用户可同时填写 Markdown 说明文字(为什么这段代码值得沉淀、怎么用)
- 分支代码更新后,条目查看时看到的是最新代码(引用非快照)

**类型 B:直接创建(Markdown 文档型)**
- 标题 + 类型(code_snippet/pattern/pitfall/doc)+ 标签 + Markdown 正文
- 编辑器带预览(编辑/预览切换)
- 创建即 published(沿用现有人工条目规则)

### R2:知识条目详情页(Markdown 查看)

- 条目从列表可点进详情页(独立路由,可分享链接)
- 详情页完整渲染 Markdown 正文(标题/列表/代码块/表格/链接)
- 类型 A 条目:详情页上半为说明 Markdown,下半为代码引用区(按路径逐个拉取渲染,显示 repo/branch/path 来源标注)
- 详情页展示:类型徽章、标签、创建者(AI/人)、创建时间、状态(draft/published)、source_links 链接
- draft 条目:项目 editor/超管可见「发布」按钮;项目 owner 可见「提升到平台级」按钮(沿用现有接口)

### R3:条目编辑与删除

- 创建者可编辑自己创建的人工条目(title/type/tags/content/代码引用);AI 条目仅可编辑标签
- 删除:创建者本人 + 项目 owner/editor 可删;平台级条目仅超管可删
- 编辑/删除入口在详情页

### R4:列表与入口修补

- 列表卡片显示真实摘要(content 前 100 字,纯文本截取)
- ArchivePage「查看」按钮接通详情页
- 新建 Dialog 升级:两种类型 Tab 切换(关联代码 / 直接创建),类型 A 含仓库/分支/路径选择器(仅项目绑定的 GitLab 仓库,多路径上限 10 个)

## 范围外

- 知识条目版本管理(主 PRD 已明确不做)
- 条目权限细分(沿用:项目内成员可见项目库,平台库全员可见)
- 知识推荐
- 代码引用的行区间选择(V1 到文件/目录粒度)
- 类型 A 的快照模式(固定 commit 存死代码)——本期只做引用,快照后续按需加
- 平台级直建入口——平台级维持「项目级建 → owner promote」单通道(已确认)

## 异常场景

| 场景 | 处理 |
|---|---|
| 类型 A 选择的仓库已解绑/分支已删 | 详情页代码区显示「代码来源不可达」降级,说明 Markdown 仍可见 |
| 路径不存在或拉取失败 | 该路径块显示错误占位,不阻塞其他路径 |
| 拉取代码失败/目录过大 | 加载失败可重试;目录递归 >200 文件截断并提示 partial;单文件全量不截断 |
| 删除已 promote 到平台级的条目 | 平台级条目仅超管可删(原创建者不可删) |
| 平台级页面不提供新建入口 | /knowledge 页无新建按钮,统一走项目级建后 promote |

## 确认记录(2026-09-25)

| 问题 | 结论 |
|---|---|
| 类型 A 代码内容策略 | **引用实时拉取**;分支更新 → 条目内容跟着变;快照模式后续按需另立迭代 |
| 代码来源 | **仅平台绑定 GitLab 仓库**,走现有 GitLab token,不支持外部 URL |
| 路径数量 | **多路径(同库同分支),上限 10 个** |
| 平台级直建入口 | **本期不做**,维持 promote 单通道 |
| AI 条目编辑 | **仅可编辑标签**,正文为归档产物不可改(要改正文另建人工条目) |
| 详情页形态 | **独立路由页** /knowledge/{entry_id},可分享链接 |
| 目录代码加载 | **递归拉全、树状呈现**;单文件不截断;服务端本地缓存(TTL 5 分钟),「重新拉取」穿透;防护:目录 >200 文件截断 partial |
