# R4:原型链接字段(多条)

- **状态**:⬜ | **依赖**:无(与 R1 同迁) | **模块**:M1+M2

## PRD 引用(PRD-B R1)

链接列表 [{label ≤20 可空, url http(s) 必填}] ≤10 条;创建/详情可维护;详情点击新开(rel=noopener);非 http(s) 拦截。

## 接口契约

- **迁移**:requirements 加 `prototype_links JSON NULL` → DEPLOY.md
- Create/Update schema 加 prototype_links:list[{label:str|None,url:str}]|None;service 校验:条数 ≤10、url http(s)/https 开头、label 截断 20——非法整组 400(与关联用户静默剔除不同,链接格式错误显式拒绝)
- 响应 RequirementDetailData 加 prototype_links

## 实现要点

- 文案:「添加链接」「链接标签(可选)」「URL」「最多 10 条」「URL 需以 http(s):// 开头」
