# R7.F1:修复工作台任务卡取数 key 错位(BUG-KB-006)

- **状态**:✅(verified,BUG-KB-006 迁移 ISSUES.md)
- **根因**(API+DB 实证):summary 后端返回键为 `dev_tasks/test_tasks/release_tasks`,Dashboard.tsx DIMS 按 `key:'dev'|'test'|'release'` 直取 `summary[d.key]` → 三张任务卡对所有用户恒 0/空(需求卡同名 requirements 侥幸正常);后端 R7 口径正确(实测该用户 dev total=8)

## 实现要点

Dashboard.tsx DIMS 增加 `skey` 字段('dev'→'dev_tasks' 等)映射后端真实键;替换 L94/L110 两处 `summary[d.key]` 取数为 `summary[d.skey]`。仅前端约 5 行。

1. API:GET /api/dashboard/summary 的 dev_tasks.total>0 时,首页「开发任务」卡显示该 total 与 recent 行

3. tsc 零错误
