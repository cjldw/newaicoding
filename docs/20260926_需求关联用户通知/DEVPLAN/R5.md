# R5:交付时间字段+逾期标记

- **状态**:⬜ | **依赖**:无(与 R1 同迁) | **模块**:M1+M2

## PRD 引用(PRD-B R2)

delivery_date DATE 列(独立列,巡检 WHERE+排序);创建/详情可维护(date picker 到天);列表「交付时间」列(创建时间后);未终态且 <今天 → 红色「已逾期」徽章;终态(done/archived)不标。

## 接口契约

- **迁移**:requirements 加 `delivery_date DATE NULL` → DEPLOY.md
- Create/Update schema 加 delivery_date:date|None;响应加;无早于今天限制

## 实现要点

- 前端表单 date picker(现有体系无 DatePicker 则原生 input[type=date] 样式化);详情基本信息卡展示(无值不渲染行);列表列:日期 + 逾期徽章(判定:['done','archived'].includes(status) 不标;date < GMT+8 今天)
- 「今天」后端 = UTC naive +8h(调研 :233 先例)
