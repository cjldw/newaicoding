## 服务端行为规格(负向探查)

- 容器启动失败/exec 失败 → 502 可重试,旧数据保留(不因失败清库)(挖掘:一致性域)
- 并发采集 → 锁内串行,第二次等待后直接返回首次结果(挖掘:并发域)
- 采集结果为空 → 清空旧表入库+警告「镜像未内置」(挖掘:状态域)
- Runner 离线 → 502 提示无可用 Runner(挖掘:状态域)
