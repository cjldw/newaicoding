## 接口契约

- **新建** skill_market_service.py:httpx 双适配器——
  - modelscope:PUT {base}/api/v1/dolphin/skills body {Query,PageSize,PageNumber:1}(⚠️ 过滤字段是 Query)→ Data.SkillList 映射(name=Name,ref=Path/Name,installs=DownloadCount)
  - skillssh:GET {base}/api/search?q=&limit= → skills[] 映射(name,ref=owner/repo/slug=skillId,installs)
- GET /api/skills/market/search(api/skills.py):JWT;q 必填(空 400);limit 默认 20 上限 50;market 须在源列表(400);缓存键 (market,q,limit) TTL 300s;市场超时/5xx → 502「市场暂不可用」
- 响应 data:{market, items:[{name,description,installs,ref,market}]}

- q 前后空格 trim;特殊字符 URL encode 原样传递
