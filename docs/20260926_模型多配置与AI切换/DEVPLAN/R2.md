- **接口契约**:

  ### 接口 1:创建配置(复用现有端点,扩展请求/校验)
  - 类型:复用现有 `POST /api/projects/{project_id}/model-configs`(`backend/app/api/projects.py:301`;service `model_config_service.create_config`)
  - 鉴权:`require_project_role(..., "owner")`(403=1901)
  - 请求体:

    | 参数 | 类型 | 必填 | 说明 |
    |---|---|---|---|
    | name | string(1-64) | 是 | 同项目唯一(13002) |
    | base_url | string(≤255) | 是 | http/https |
    | api_key | string(≤255) | 是 | 明文,服务端 AES-GCM 加密 |
    | models | string[] | 是 | 1-10 项,每项 1-64 字符,去重(13008/13009) |
    | default_model | string | 是 | 必须 ∈ models;缺省取 models[0] |
    | is_default | bool | 否(默认 false) | 同项目唯一(13003) |
    | enabled | bool | 否(默认 true) | - |

  - 响应结构(`data`):

    | 字段 | 类型 | 说明 |
    |---|---|---|
    | config_id | string(uuid) | - |
    | name / base_url | string | - |
    | api_key_masked | string | 前4+***+后4(viewer 响应无此字段) |
    | models | string[] | - |
    | default_model | string | - |
    | model | string | =default_model(双写兼容字段) |
    | is_default / enabled | boolean | - |
    | created_by | {user_id, username} | - |
    | created_at | datetime | - |

  - 错误码与异常:13001(连通测试失败,message 含模型名)、13002、13003、13007(配置组超限)、13008(模型名超限)、13009(models 内重复)
  - 分页格式:无

  ### 接口 2:更新配置(复用现有端点,扩展)
  - 类型:复用现有 `PATCH /api/projects/{project_id}/model-configs/{config_id}`(`projects.py:335`)
  - 鉴权:owner(1901)
  - 请求体:全字段 Optional;`models`/`default_model` 替代原 `model`(原 `model` 键若出现按单个模型名兼容处理:并入 models 去重)

    | 参数 | 类型 | 必填 | 说明 |
    |---|---|---|---|
    | name / base_url / api_key / is_default / enabled | 同创建 | 否 | 沿用 R13 语义 |
    | models | string[] | 否 | 整列表替换;≤10、去重 |
    | default_model | string | 否 | 必须 ∈ 更新后 models |

  - 响应结构:同接口 1 响应
  - 错误码与异常:13001(重测失败,message 含模型名)、13002、13003、13008、13009;default 配置可编辑
  - 分页格式:无

  ### 接口 3:配置列表(复用现有端点,扩展响应)
  - 类型:复用现有 `GET /api/projects/{project_id}/model-configs`(`projects.py:251`)
  - 鉴权:项目成员或 internal 可见回退;viewer 响应无 api_key_masked
  - 响应结构:`{items: [接口 1 响应结构]}`(排序沿用:default 优先、created_at 升序)
  - 错误码与异常:404(非成员且非 internal)
  - 分页格式:无(全量,≤10 组)

  ### 接口 4:生效配置查询(复用现有端点,响应语义扩展)
  - 类型:复用现有 `GET /api/projects/{project_id}/model-configs/resolvable`(`projects.py:269`)
  - 响应结构:`{effective_source: "project"|"platform"|"none", base_url, model, api_key_masked}`;`model` 语义改为**生效的默认模型名**(项目=default 配置的 default_model;平台=llm_default_model)
  - 错误码与异常:resolve 失败不抛错,回 `effective_source: "none"`(沿用)
  - 分页格式:无

  ### 接口 5:连通性测试(复用现有,不变)

  - 请求体:`{base_url, api_key, model}`(单模型名;对话框添加 tag 时逐个调用)
  - 响应结构:`{success, latency_ms}`
  - 错误码与异常:13001
  - 分页格式:无

- **服务端行为规格**:

  | 行为 | 规格 |
  |---|---|
  | 存量兼容(必答) | `models` 为 NULL/空 → 读作 `[model]`,`default_model` 缺失 → 读作 `model`;新代码读老数据不 500;无回填脚本;`model` 列继续写入(=default_model)保持旧路径可读 |
  | 连通测试(create) | 服务端对 `models` **全量逐个**测试(`llm_service.test_connectivity` 顺序执行,≤10 次),任一失败 → 13001 整批拒绝,message 含失败模型名 |
  | 连通测试(update) | base_url 或 api_key 变更 → 全量重测;仅 models 变更 → 仅对**新增项**测试(存量项已测过);仅删除/改名/启停/default → 不测(已确认 2026-09-26) |
  | 唯一性 | models 列表内去重 → 13009;跨配置模型名允许重复(不同接入);配置名唯一 13002 沿用 |
  | 上限 | 配置组数:创建前 count 校验,≥10 → 13007(并发下后到者拒);models >10 → 13008 |
  | 删除保护 | default 配置不可删(13004)沿用;default_model 无删除保护(可删,自动顺延) |
  | 校验一致性 | `default_model ∈ models` 服务端强校验(前端顺延逻辑仅体验,不信任前端) |
  | 响应最小化 | api_key 只回打码;viewer/非成员响应无 api_key_masked 字段(沿用);审计 detail 只含 name/model,无 key |
  | 查询域 | 列表接口无分页/排序参数:items 全量返回(≤10 组),排序服务端固定(default 优先、created_at 升序),不接收 orderBy/过滤参数,排序注入无入口 → 不适用(原因:无用户可控查询位) |
  | 并发/幂等 | 同名并发创建 → 后到者 13002(唯一约束兜底);上限并发 → 后到者 13007 |

- **页面交互流程**:
  - 新建:点「新建配置」→ 打开对话框 → 填 name/base_url/api_key → 逐个添加模型名(每项即时测试)→ 可勾选"设为默认" → 「保存」→ create → 成功:关对话框、列表刷新出新配置;失败:留对话框、错误提示

  - 取消/关闭对话框:不保存,无残留(本地 tag 态丢弃)
