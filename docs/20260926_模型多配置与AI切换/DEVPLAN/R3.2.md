- **状态**:⬜ 未开始
- **PRD 引用**(R3 前端部分;后端契约见 R3.1):
  - **边界**:做什么 = TaskChat 发送区模型选择器(项目配置/平台默认两组,当前生效高亮);选中调切换接口;new_session/session_reset 提示;失效回退回显与提示;assistant 气泡模型小字标注。不做什么 = 消息级临时选择、用户级偏好、其他入口、时间戳/tokens 小字(仅模型名)。

- **实现要点**:
  - ①api/tasks.ts 加类型(ModelOptions/CurrentModel/SwitchModelResponse)与两个 hooks;TaskMessage 类型加 `model?: string | null`。
  - ②TaskChat 内新增局部组件 `ModelPicker`({taskId, projectId}):触发按钮 + 弹层(state 开合,外点关闭);打开时 useTaskModelOptions 取数,loading 态显示"加载中...",current=null 时按钮禁用(title"未配置可用模型")。
  - ③清单渲染:project_configs 组(组标题「项目配置」;每配置一个小标题行=name(is_default 加「默认」Badge outline) + 其 models 逐项,default_model 置顶带「默认」小徽章)、platform 组(组标题「平台默认」,default_model 置顶);底部固定「恢复默认(回退链)」项(current.selected=false 时高亮)。
  - ④切换:mutation pending 时对应项禁用;成功按响应 new_session/stale toast;current.model 截断显示在触发按钮。
  - ⑤气泡:assistant 消息 `msg.model` 非空 → 气泡下 `.m-meta` 行 `{msg.model}`(AI 气泡左对齐);user 消息不显示。
  - ⑥发送响应处理:onSuccess 里 model_stale/session_reset toast + invalidate options。
  - 页面生成逻辑数据映射:选择器项 = project_configs[].models 循环(项 key=`${config_id}:${m}`);触发按钮文本 = options.current?.model;气泡小字 = messages[].model。
- **页面交互流程**:
  - 打开:点触发按钮 → 弹层开(缓存数据即显,后台 refetch);外点/Escape → 关
  - 切换:点项 → PUT → 成功:弹层关、按钮文本更新、toast;失败:弹层关、按钮文本不变、toast 错误
  - 恢复默认:点底部项 → PUT null/null → 同上,按钮显示回退链解析模型
  - 发送(现有链路不变):发送成功响应含 model_stale/session_reset → 对应 toast
  - 面板刷新/重进任务:options 重取,按钮/高亮与任务持久选择一致
- **错误处理行**:
  - model-options 加载失败(网络/500)→ 触发按钮禁用态 + title"模型列表加载失败";重试靠再次打开弹层(refetch)
  - current=null(未配置)→ 按钮禁用,title"未配置可用模型"
  - PUT 13006/403/网络错误 → toast message,选择回弹
  - 防重:切换 pending 时弹层项全部禁用;发送按钮防重沿用
- **控件联动**:

  | 触发控件 | 事件 | 响应行为 |

  | 模型触发按钮 | click | 弹层开合 toggle;打开时 refetch |
  | 弹层项 | click | PUT 切换(见交互流程);pending 禁用 |
