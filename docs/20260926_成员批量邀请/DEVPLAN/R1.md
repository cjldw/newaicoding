# R1:候选用户列表接口(owner 专属)

- **状态**:⬜
- **依赖**:无
- **模块**:M1 后端

## PRD 引用

owner 从平台用户列表浏览候选:分页+搜索(昵称/手机号模糊);复用 admin/users 打码与过滤;返回 is_member/status 标记供前端禁选。异常:非 owner 访问 403。

## 接口契约

**新建** `GET /api/projects/{project_id}/candidate-users?q=&page=&page_size=`:
- 鉴权:require_project_role(project, user, "owner")(超管经 get_project_role 旁路天然通过,与现 invite 同口径);非 owner 403/1901
- q:对 phone(LIKE)+nickname(LIKE)模糊;page/page_size(默认 20,上限 100)
- 数据源:users 表(全量平台用户);联查项目成员表标 is_member;**排除条件无**(disabled 返回,前端禁选)
- 响应 data:`{items:[{user_id, phone(打码 mask_phone 复用 admin 同函数), nickname, avatar_url, status, is_member}], total, page, page_size}`
- 挂载:backend/app/api/projects.py(成员路由区旁),service 逻辑进 project_member_service

## 权限矩阵

| 角色 | 候选列表 |
|---|---|
| 项目 owner | ✅ |
| editor/viewer/非成员 | 403 |
| 超管 | ✅ |

## 实现要点

- 打码函数复用 admin/users_admin.py 的 mask_phone(导入复用,不复制)
- is_member:一次查询 project_members 全量 user_id 集合,内存标记(成员 ≤50)
- 搜索为空 q 时返回全部用户分页(平台用户量可控)
- 日志:入口 q/page + 耗时(照现有风格)
