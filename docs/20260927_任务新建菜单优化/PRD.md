# PRD:任务新建菜单优化

> 创建日期:2026-09-27
> 状态:已确认

## 背景与目标

当前 `/manage/tasks` 页面的任务创建存在以下问题:
1. 页头有三个独立按钮(新建开发任务/新建测试任务/新建发布任务),入口分散
2. 项目和需求的下拉选择器不支持搜索,项目/需求多时难以定位
3. 任务类型由入口按钮决定,无法在表单内灵活选择

优化目标:
- 统一任务创建入口为单一按钮,表单内选择类型
- 项目和需求选择器支持搜索(后端搜索)
- 为未来任务类型扩展预留注册机制

## 用户故事

1. 作为项目成员,我希望在统一入口创建任务并选择类型,以便不需要记住多个按钮的位置
2. 作为项目成员,我希望通过搜索快速定位项目和需求,以便在项目/需求较多时提高创建效率
3. 作为项目成员,我希望任务类型可扩展,以便未来新增类型时无需改变核心流程

## 需求点清单

### R1:统一任务创建入口

- **描述**:将页头三个分类型按钮(新建开发任务/新建测试任务/新建发布任务)合并为单一的"新建任务"按钮,点击打开统一创建表单
- **触发场景**:用户在 `/manage/tasks` 页面点击页头"新建任务"按钮
- **前置条件**:用户已登录且有任务创建权限
- **边界定义**:
  - 做什么:移除三个分类型按钮,替换为单一"新建任务"按钮;表单内新增任务类型选择器
  - 不做什么:不改变其他页面的任务创建入口(如项目详情页、需求详情页)
- **字段定义**:
  | 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
  |---|---|---|---|---|---|
  | 按钮文案 | string | - | "新建任务" | - | 页头按钮文案 |
- **交互规则**:
  | 场景/条件 | 行为/规则 | 结果/去向 |
  |---|---|---|
  | 点击"新建任务"按钮 | 打开统一创建表单 | 表单弹窗显示 |
- **依赖**:R2(表单字段)、R3(选择器)
- **异常与边界场景**:
  - 无权限创建任务:按钮不显示或点击后提示无权限
- **验收标准**:
  1. 页头仅显示一个"新建任务"按钮
  2. 点击按钮打开统一创建表单
  3. 原有三个按钮不再显示

### R2:任务类型选择器

- **描述**:表单内新增任务类型下拉选择器,支持开发/测试/发布三种类型,采用类型注册机制便于扩展
- **触发场景**:用户在创建表单中选择任务类型
- **前置条件**:表单已打开
- **边界定义**:
  - 做什么:提供类型选择器,静态显示所有可选类型;采用注册机制,新增类型时只需新增组件并注册
  - 不做什么:不根据需求状态动态过滤可选类型(后端兜底校验)
- **字段定义**:
  | 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
  |---|---|---|---|---|---|
  | type | enum | 是 | 空 | 必须为 dev/test/release 之一 | 任务类型 |
- **交互规则**:
  | 场景/条件 | 行为/规则 | 结果/去向 |
  |---|---|---|
  | 选择类型 | 显示对应类型特有字段插槽 | 表单更新 |
  | 切换类型 | 清空类型特有字段,保留公共字段 | 表单更新 |
  | 未选择类型提交 | 拦截提交,提示"请选择任务类型" | 表单保持 |
- **依赖**:R5(类型特有字段插槽)
- **异常与边界场景**:
  - 后端返回类型不存在:显示错误提示
- **验收标准**:
  1. 类型选择器显示开发/测试/发布三个选项
  2. 选择类型后显示对应特有字段
  3. 切换类型时清空特有字段

### R3:可搜索的项目与需求选择器

- **描述**:项目和需求选择器支持搜索,采用自定义搜索面板(参考 RelatedUserSelect),搜索走后端接口(debounce 300ms)
- **触发场景**:用户在创建表单中点击项目或需求选择器
- **前置条件**:表单已打开
- **边界定义**:
  - 做什么:提供搜索面板,支持输入搜索;项目搜索调后端接口,需求搜索根据选中项目调后端接口
  - 不做什么:不做前端过滤(数据量可能增长,统一后端搜索)
- **字段定义**:
  | 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
  |---|---|---|---|---|---|
  | project_id | string | 是 | 空 | 必须为有效项目 ID | 关联项目 |
  | req_id | string | 是 | 空 | 必须为有效需求 ID | 关联需求 |
- **交互规则**:
  | 场景/条件 | 行为/规则 | 结果/去向 |
  |---|---|---|
  | 点击项目选择器 | 展开搜索面板,显示前 20 个项目 | 面板显示 |
  | 输入项目搜索关键词 | debounce 300ms 后调后端搜索接口 | 列表更新 |
  | 选择项目 | 清空已选需求,加载该项目需求列表 | 需求选择器重置 |
  | 点击需求选择器 | 展开搜索面板,显示该项目前 20 个需求 | 面板显示 |
  | 输入需求搜索关键词 | debounce 300ms 后调后端搜索接口 | 列表更新 |
  | 选择需求 | 关闭面板,显示已选需求 | 面板关闭 |
- **依赖**:R1(表单)
- **异常与边界场景**:
  - 项目列表为空:显示"暂无项目,请先创建项目"
  - 需求列表为空:显示"该项目暂无可选需求"
  - 搜索无匹配结果:显示"无匹配结果"
  - 搜索接口失败:显示"搜索失败,请重试"
- **验收标准**:
  1. 项目选择器支持搜索,搜索走后端接口
  2. 需求选择器支持搜索,搜索走后端接口
  3. 切换项目时清空已选需求
  4. 空态和无匹配时显示对应文案

### R4:统一表单结构

- **描述**:任务创建表单分为公共字段和类型特有字段插槽,公共字段包括项目/需求/类型/标题/描述,类型特有字段根据选中类型动态显示
- **触发场景**:用户在创建表单中填写字段
- **前置条件**:表单已打开
- **边界定义**:
  - 做什么:公共字段统一展示;类型特有字段通过插槽机制动态渲染
  - 不做什么:不改变后端接口参数(前端组装 payload 时适配)
- **字段定义**:
  | 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
  |---|---|---|---|---|---|
  | project_id | string | 是 | 空 | 有效项目 ID | 公共字段 |
  | req_id | string | 是 | 空 | 有效需求 ID | 公共字段 |
  | type | enum | 是 | 空 | dev/test/release | 公共字段 |
  | title | string | 否 | 空 | max_length=128 | 公共字段,留空取需求标题 |
  | description | string | 否 | 空 | - | 公共字段,留空后端生成默认 |
  | deploy_port | number | 条件必填 | 空 | 10000-10099 | release 类型特有字段 |
- **交互规则**:
  | 场景/条件 | 行为/规则 | 结果/去向 |
  |---|---|---|
  | 选择 release 类型 | 显示部署端口字段 | 表单更新 |
  | 选择 dev/test 类型 | 隐藏部署端口字段 | 表单更新 |
  | 提交时校验 | 检查必填字段 | 通过则提交,失败则提示 |
- **依赖**:R2(类型选择器)、R3(项目/需求选择器)、R5(类型特有字段)
- **异常与边界场景**:
  - 必填字段未填:显示错误提示,不提交
  - 端口格式错误:显示"端口需为 10000-10099"
  - 后端返回错误(4001/4002/4003):显示对应错误文案
- **验收标准**:
  1. 公共字段正确显示
  2. 类型特有字段根据类型动态显示/隐藏
  3. 必填字段校验正确
  4. 提交成功后跳转任务详情页

### R5:类型特有字段插槽机制

- **描述**:为每种任务类型提供特有字段插槽,采用注册机制,新增类型时只需新增组件并注册
- **触发场景**:用户选择任务类型后,渲染对应类型的特有字段
- **前置条件**:类型已选择
- **边界定义**:
  - 做什么:提供插槽注册表,类型 → 组件映射;根据类型动态渲染组件
  - 不做什么:不改变公共字段逻辑
- **字段定义**:
  | 类型 | 特有字段 | 说明 |
  |---|---|---|
  | dev | 无 | 仅公共字段 |
  | test | 无 | 仅公共字段,显示提示文案 |
  | release | deploy_port | 部署端口,10000-10099 |
- **交互规则**:
  | 场景/条件 | 行为/规则 | 结果/去向 |
  |---|---|---|
  | 选择 dev | 不渲染特有字段 | 表单保持 |
  | 选择 test | 显示提示文案"AI 基于 PRD 验收标准 + 测试仓库存量用例生成用例,人审后执行" | 表单更新 |
  | 选择 release | 显示部署端口输入框 | 表单更新 |
- **依赖**:R2(类型选择器)
- **异常与边界场景**:
  - 类型未注册:显示"类型配置错误"
- **验收标准**:
  1. dev 类型无特有字段
  2. test 类型显示提示文案
  3. release 类型显示端口字段
  4. 新增类型时可通过注册机制扩展

## 非功能需求

- 性能:搜索接口 debounce 300ms,避免频繁请求
- 兼容性:保持与现有浏览器兼容(Chrome/Firefox/Safari 最新两版)

## 范围外

- 不改变其他页面的任务创建入口(项目详情页、需求详情页)
- 不改变后端任务创建接口(前端适配现有接口)
- 不实现任务类型的动态配置(仍为前端硬编码 + 注册机制)
