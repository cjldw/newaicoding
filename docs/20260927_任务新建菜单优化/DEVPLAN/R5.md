## 实现要点

### 页面结构说明

**当前状态**:三种类型的特有字段硬编码在 QuickCreateDialog 中,通过条件渲染显示。

**目标状态**:采用组件注册表方式,每种类型的特有字段封装为独立组件,主表单根据类型动态渲染。

**改动范围**:
- 新建 `TaskTypeFields.tsx` - 类型特有字段组件与注册表
- `TaskCreateDialog.tsx` - 根据 type 状态动态渲染对应组件

**组件注册表结构**:
```typescript
// TaskTypeFields.tsx
import type { ComponentType } from 'react'
import type { TaskType } from '@/api/tasks'

// 组件接口定义
export interface TaskTypeFieldProps {
  value: any
  onChange: (value: any) => void
  disabled?: boolean
  error?: string
}

// 各类型组件
const DevTaskFields: ComponentType<TaskTypeFieldProps> = () => null // dev 无特有字段
const TestTaskFields: ComponentType<TaskTypeFieldProps> = ({ ... }) => (
  <div className="hint">AI 基于 PRD 验收标准 + 测试仓库存量用例生成用例,人审后执行</div>
)
const ReleaseTaskFields: ComponentType<TaskTypeFieldProps> = ({ value, onChange, disabled, error }) => (
  <div className="field">
    <label>部署端口 *</label>
    <Input 
      type="number" 
      value={value.deploy_port || ''} 
      onChange={(e) => onChange({ ...value, deploy_port: Number(e.target.value) })}
      placeholder="10000-10099"
      disabled={disabled}
      className={error ? 'border-red-border' : undefined}
    />
    {error && <div className="text-xs text-red-fg mt-1">{error}</div>}
    <div className="hint">全平台唯一,范围 10000-10099</div>
  </div>
)

// 注册表
export const TYPE_FIELD_COMPONENTS: Record<TaskType, ComponentType<TaskTypeFieldProps> | null> = {
  dev: null, // dev 无特有字段
  test: TestTaskFields,
  release: ReleaseTaskFields,
}
```

**TaskCreateDialog 集成方式**:
```typescript
// TaskCreateDialog.tsx
import { TYPE_FIELD_COMPONENTS, type TaskTypeFieldProps } from './TaskTypeFields'

// 表单状态
const [typeSpecificData, setTypeSpecificData] = useState<any>({})

// 切换类型时清空
const handleTypeChange = (newType: TaskType) => {
  setType(newType)
  setTypeSpecificData({}) // 清空类型特有字段
}

// 渲染插槽
const TypeFieldComponent = TYPE_FIELD_COMPONENTS[type]
{TypeFieldComponent && (
  <TypeFieldComponent
    value={typeSpecificData}
    onChange={setTypeSpecificData}
    disabled={mutation.isPending}
    error={typeSpecificError}
  />
)}
```

## 扩展机制说明

**新增类型的步骤**:
1. 在 `TaskTypeFields.tsx` 中新增组件(如 `NewTypeFields`)
2. 在 `TYPE_FIELD_COMPONENTS` 注册表中添加映射
3. 在 `TaskCreateDialog.tsx` 的表单提交逻辑中处理新类型的特有字段
4. 无需修改主表单结构,符合开闭原则

**示例:新增"运维"类型**
```typescript
// 1. 新增组件
const OpsTaskFields: ComponentType<TaskTypeFieldProps> = ({ value, onChange, disabled }) => (
  <div className="field">
    <label>运维脚本 *</label>
    <Textarea 
      value={value.script || ''} 
      onChange={(e) => onChange({ ...value, script: e.target.value })}
      placeholder="输入运维脚本"
      disabled={disabled}
    />
  </div>
)

// 2. 注册
export const TYPE_FIELD_COMPONENTS: Record<TaskType, ComponentType<TaskTypeFieldProps> | null> = {
  dev: null,
  test: TestTaskFields,
  release: ReleaseTaskFields,
  ops: OpsTaskFields, // 新增
}
```
