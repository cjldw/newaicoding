## 实现要点

### 页面结构说明

**当前状态**:任务类型由入口按钮决定,表单内无类型选择器。

**目标状态**:表单内新增任务类型下拉选择器,支持开发/测试/发布三种类型。

**改动范围**:
- `TaskCreateDialog.tsx` - 新增类型选择器字段(表单第一个字段,位于项目选择器之后)
- 类型选择器使用现有 Select 组件
- 类型选项:开发(dev)/测试(test)/发布(release)

### 页面交互流程

| 交互 | 去向 | 刷新 |
|---|---|---|
| 选择任务类型 | 更新表单 type 字段 | 显示对应类型特有字段(R5) |
| 切换任务类型 | 清空类型特有字段 | 表单更新 |

### 控件联动

| 触发控件 | 事件 | 响应行为 |
|---|---|---|
| 任务类型选择器 | onChange | 更新 type 状态,清空类型特有字段 |

### 文案清单

| 位置 | 文案 |
|---|---|
| 类型选择器 label | 任务类型 |
| 类型选择器 placeholder | 请选择任务类型 |
| 开发选项 | 开发 |
| 测试选项 | 测试 |
| 发布选项 | 发布 |

## 设计规范

同样板页(Select 组件默认样式)。

**Token**:
- label 样式:`text-sm font-medium text-text`
- select 样式:`input` class

**布局**:
- 字段位置:表单第一个字段(项目选择器之后)
- 字段结构:label + select,flex-col 布局,gap-1.5

**组件状态**:
- 默认:显示 placeholder
- 选中:显示选中类型
- disabled:灰色背景(当提交中时)
