## 实现要点

### 页面结构说明

**当前状态**:项目/需求使用原生 `<select>` 下拉,不支持搜索。

**目标状态**:项目/需求使用自定义搜索面板,支持输入搜索(debounce 300ms 调后端接口)。

**改动范围**:
- 新建 `SearchableSelect.tsx` - 通用可搜索选择器组件(参考 RelatedUserSelect)
- `TaskCreateDialog.tsx` - 使用 SearchableSelect 替换项目/需求选择器
- `projects.ts` - 新增 `searchProjects(q: string)` API
- `requirements.ts` - 新增 `searchRequirements(projectId: string, q: string)` API

### 页面交互流程

| 交互 | 去向 | 刷新 |
|---|---|---|
| 点击项目选择器 | 展开搜索面板,显示前 20 个项目 | 面板显示 |
| 输入项目搜索关键词 | debounce 300ms 后调后端搜索接口 | 列表更新 |
| 选择项目 | 清空已选需求,加载该项目需求列表 | 需求选择器重置 |
| 点击需求选择器 | 展开搜索面板,显示该项目前 20 个需求 | 面板显示 |
| 输入需求搜索关键词 | debounce 300ms 后调后端搜索接口 | 列表更新 |
| 选择需求 | 关闭面板,显示已选需求 | 面板关闭 |

### 控件联动

| 触发控件 | 事件 | 响应行为 |
|---|---|---|
| 项目选择器 | onChange | 清空已选需求,重新加载需求列表 |
| 需求选择器 | onChange | 更新 req_id 状态 |

### 文案清单

| 位置 | 文案 |
|---|---|
| 项目选择器 label | 关联项目 |
| 项目选择器 placeholder | 请选择项目 |
| 项目搜索框 placeholder | 搜索项目(名称) |
| 需求选择器 label | 关联需求 |
| 需求选择器 placeholder | 请选择需求 |
| 需求搜索框 placeholder | 搜索需求(标题/描述) |
| 项目列表为空 | 暂无项目,请先创建项目 |
| 需求列表为空 | 该项目暂无可选需求 |
| 搜索无匹配结果 | 无匹配结果 |
| 搜索接口失败 | 搜索失败,请重试 |

## 设计规范

同样板页(`RelatedUserSelect.tsx`)。

**Token**:
- 触发框样式:`input` class
- 下拉面板:`bg-surface border-border shadow-lg z-10`
- 搜索框:`h-8 text-xs`
- 选项行:`hover:bg-surface-strong`

**布局**:
- 触发框:显示已选值 + 下拉箭头
- 下拉面板:搜索框 + 滚动列表(max-h-60)
- 选项行:图标 + 文案 + 勾选态

**组件状态**:
- 默认:显示 placeholder
- 展开:显示下拉面板
- 加载中:显示"加载中..."
- 空态:显示对应空态文案
- 错误:显示"搜索失败,请重试"
