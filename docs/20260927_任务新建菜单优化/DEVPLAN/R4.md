## 实现要点

### 页面结构说明

**当前状态**:三个分类型按钮对应三个不同的表单结构。

**目标状态**:统一表单结构,包含公共字段和类型特有字段插槽。

**改动范围**:
- 新建 `TaskCreateDialog.tsx` - 统一任务创建表单
- 新建 `TaskTypeFields.tsx` - 类型特有字段注册表与组件

**表单字段顺序(从上到下,单列布局)**:
1. **关联项目**(搜索选择器,R3.2 实现) - 必填,显示红色星号
2. **关联需求**(搜索选择器,R3.2 实现) - 必填,显示红色星号,依赖项目选择
3. **任务类型**(下拉选择器,R2 实现) - 必填,显示红色星号
4. **任务标题**(Input 输入框) - 可选,placeholder "留空默认取需求标题"
5. **任务描述**(Textarea 文本域) - 可选,placeholder "本次要让 AI 做什么?",rows=3
6. **类型特有字段插槽**(R5 实现) - 根据选中类型动态渲染

**表单布局**:单列布局,所有字段独占一行,纵向排列,gap-4。

### 页面交互流程

| 交互 | 去向 | 刷新 |
|---|---|---|
| 打开对话框 | 初始化表单状态 | 表单清空 |
| 选择项目 | 清空已选需求,加载该项目需求列表 | 需求选择器重置 |
| 选择需求 | 更新 req_id 状态 | 无 |
| 选择任务类型 | 更新 type 状态,清空类型特有字段 | 显示对应类型特有字段 |
| 填写标题/描述 | 更新表单状态 | 无 |
| 点击"创建"按钮 | 前端校验 → 调用 createTask 接口 | 成功后跳转任务详情页 |
| 点击"取消"按钮 | 关闭对话框,重置表单 | 无 |
| 接口返回错误 | 显示错误提示 Alert | 表单保持 |

## 设计规范

同样板页(QuickCreateDialog)。

**Token**:
- 表单间距:`gap-4`
- label 样式:`text-sm font-medium text-text`
- 输入框样式:`input` class
- 必填标记:`text-red-fg`
- 对话框宽度:`w-[440px]`

**布局**:
- 单列布局,所有字段独占一行
- 字段结构:label + 输入控件,flex-col 布局,gap-1.5
- 必填字段:label 后显示红色星号 `*`
- 对话框内容区:`flex flex-col gap-4 py-2`

**组件状态**:
- 默认:显示表单
- 提交中:按钮显示"创建中...",禁用所有输入
- 错误:显示错误提示 Alert(variant="error")
- 成功:关闭对话框,跳转详情页

## 接口契约

复用现有 `POST /api/requirements/{req_id}/tasks` 接口。

请求参数:
```typescript
{
  type: 'dev' | 'test' | 'release',
  title: string,
  description: string,
  deploy_port?: number, // release 类型特有
}
```

响应:
```typescript
{
  task_id: string
}
```

错误码:
- 4001: 需求状态不允许
- 4002: 未绑 GitLab token
- 4003: 并发超限(3)

## 字段定义

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|---|---|---|---|---|---|
| project_id | string | 是 | 空 | 有效项目 ID | 关联项目 |
| req_id | string | 是 | 空 | 有效需求 ID | 关联需求 |
| type | enum | 是 | 空 | dev/test/release | 任务类型 |
| title | string | 否 | 空 | max_length=128 | 任务标题,留空取需求标题 |
| description | string | 否 | 空 | - | 任务描述,留空后端生成默认 |

## 业务/交互规则

| 场景/条件 | 行为/规则 | 结果/去向 |
|---|---|---|
| 未选项目提交 | 拦截提交,提示"请选择关联项目" | 表单保持 |
| 未选需求提交 | 拦截提交,提示"请选择关联需求" | 表单保持 |
| 未选类型提交 | 拦截提交,提示"请选择任务类型" | 表单保持 |
| 提交成功 | 关闭对话框,跳转任务详情页 | 刷新列表 |
| 提交失败 | 显示错误提示 | 表单保持 |
| 切换项目 | 清空已选需求 | 需求选择器重置 |
| 切换类型 | 清空类型特有字段 | 表单更新 |
