## 实现要点

### 页面结构说明

**当前状态**:页头有三个按钮(新建开发任务/新建测试任务/新建发布任务),分别对应 `dimension='dev'|'test'|'release'`。

**目标状态**:页头仅显示一个"新建任务"按钮,点击打开统一创建表单(TaskCreateDialog)。

**改动范围**:
- `DimensionPage.tsx:157-164` - 移除三个分类型按钮,替换为单一"新建任务"按钮
- `DimensionPage.tsx:252-266` - 修改 Dialog 渲染逻辑,使用新的 `TaskCreateDialog` 组件
- `ManagePages.tsx:57-68` - TasksManage 组件调整 `createLabel` 为"新建任务"
- 新建 `TaskCreateDialog.tsx` - 统一任务创建表单组件(表单结构在 R2-R5 中完善)

### 页面交互流程

| 交互 | 去向 | 刷新 |
|---|---|---|
| 点击"新建任务"按钮 | 打开 `QuickCreateDialog` | 无 |
| 关闭对话框 | 关闭弹窗 | 无 |
| 创建成功 | 跳转任务详情页 | 刷新列表 |
