> 状态:✅ 完成
> PRD 引用:R3(可搜索的项目与需求选择器)

## 依赖

无

## 涉及模块/文件

- `backend/app/api/projects.py` - 项目列表接口新增 `q` 参数
- `backend/app/api/requirements.py` - 需求列表接口新增 `q` 参数

## 复用清单

- 现有项目列表接口:`/api/projects`
- 现有需求列表接口:`/api/requirements`

## 实现要点

### 接口契约

**项目列表接口**
- 路径:`GET /api/projects`
- 新增参数:`q: Optional[str] = Query(None, description="搜索关键字")`
- 搜索逻辑:在 `list_projects` 服务方法中,如果 `q` 不为空,添加过滤条件 `Project.name.ilike(f"%{q}%")`
- 返回格式:与现有接口一致

**需求列表接口**
- 路径:`GET /api/requirements`
- 新增参数:`q: Optional[str] = Query(None, description="搜索关键字")`
- 搜索逻辑:在 `list_requirements` 服务方法中,如果 `q` 不为空,添加过滤条件 `Requirement.title.ilike(f"%{q}%") | Requirement.description.ilike(f"%{q}%")`
- 返回格式:与现有接口一致

### 数据模型变更

无(仅查询逻辑变更)

### 权限矩阵

与现有接口一致:登录用户可见自己有权限的项目/需求。

### 服务端行为规格

- 搜索不区分大小写(`ilike`)
- 搜索匹配项目名称/需求标题/需求描述
- 搜索结果为空时返回空列表,不报错

## 完成判据

- [x] 项目列表接口支持 `q` 参数搜索
- [x] 需求列表接口支持 `q` 参数搜索
- [x] 搜索不区分大小写
- [x] 搜索结果为空时返回空列表

## 测试验证逻辑

1. 调用 `GET /api/projects?q=test`,验证返回名称包含 "test" 的项目
2. 调用 `GET /api/requirements?q=需求`,验证返回标题或描述包含 "需求" 的需求
3. 调用 `GET /api/projects?q=不存在的名称`,验证返回空列表

## 接口契约

**项目列表接口**
- 路径:`GET /api/projects`
- 方法:GET
- 鉴权:需要登录
- 请求参数:
  - `status: Optional[str]` - 项目状态(已有)
  - `page: int = 1` - 页码(已有)
  - `page_size: int = 20` - 每页数量(已有)
  - `q: Optional[str]` - 搜索关键字(新增)
- 响应结构:与现有接口一致
- 错误码:与现有接口一致

**需求列表接口**
- 路径:`GET /api/requirements`
- 方法:GET
- 鉴权:需要登录
- 请求参数:
  - `project_id: int` - 项目 ID(已有)
  - `status: Optional[str]` - 需求状态(已有)
  - `page: int = 1` - 页码(已有)
  - `page_size: int = 20` - 每页数量(已有)
  - `q: Optional[str]` - 搜索关键字(新增)
- 响应结构:与现有接口一致
- 错误码:与现有接口一致
