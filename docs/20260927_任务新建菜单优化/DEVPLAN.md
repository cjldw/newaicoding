# 开发计划:任务新建菜单优化

> PRD:./PRD.md
> 创建日期:2026-09-27
> 状态:已确认

## 需求概述

优化 `/manage/tasks` 页面的任务创建流程：
1. 将三个分类型按钮合并为单一"新建任务"入口
2. 表单内新增任务类型选择器，支持开发/测试/发布三种类型
3. 项目和需求选择器支持搜索（后端搜索）
4. 采用类型注册机制，便于未来扩展新类型

## 技术约定

**请求封装**：前端使用 `@tanstack/react-query` 管理接口请求，统一错误处理见 `frontend/src/api/client.ts`。

**路由注册**：`/manage/tasks` 路由已在 `frontend/src/router.tsx:76` 注册，组件从 `@/pages/manage/ManagePages` 导入。

**命名规范**：
- 组件：PascalCase（如 `TaskCreateDialog`）
- 文件：PascalCase.tsx（如 `TaskCreateDialog.tsx`）
- API 函数：camelCase（如 `createTask`）
- Hook：use 前缀（如 `useProjectSearch`）

**状态管理**：使用 react-query 管理服务端状态，本地表单状态用 `useState`。

**通用组件来源**：
- UI 组件：`frontend/src/components/ui/`（Dialog/Input/Button/Select/Avatar/Badge 等）
- Hooks：`frontend/src/hooks/`（useDebounce 等）
- 参考实现：`frontend/src/pages/requirements/RelatedUserSelect.tsx`（搜索面板交互）
