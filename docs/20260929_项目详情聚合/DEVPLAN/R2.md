- **实现要点**:
  1. `useProjectOverview(projectId)`:useQuery(queryKey `['project-overview', projectId]`),refetchInterval 15s(概览自动刷新,照 useTaskChanges 15s 先例);失败不上抛,由组件 isError 分支渲染
  2. 口径切换:组件内 `useState<'all'|'7d'>('all')`;累计→四卡 total/by_status/active + token total;近 7 天→仅近 7 天数字组高亮切换(R1 的 recent_7d 只有 4 计数,**近 7 天口径下四卡与 token 卡数字不变化**,切换只突出数字组——此限制记入文案与核对清单)
  3. 维度卡 mini 徽章:by_status 零值不渲染;active>0 时卡右上角 `.bdg b-blue`「进行中 N」
  4. 发布卡:latest_release 非 null 时渲染;preview_url 空串时不渲染链接
  5. 长标题统一 `nowrap` + CSS ellipsis(max-width 100%)
  6. 行点击跳转:需求行 → `/requirements/{req_id}`;任务行 → `/tasks/{task_id}`
- **页面交互流程**:
  - 进入:`/projects/:id` → 默认概览 → useProjectOverview 拉取 → 渲染统计区+列表;加载中 `.page-loading`「加载中…」
  - 查看全部(需求):点「查看全部」→ `navigate(?tab=requirements)` → 需求 Tab 渲染完整列表
  - 查看全部(任务):同上 → `?tab=tasks`
  - 需求行点击 → 跳 `/requirements/{req_id}`;返回浏览器回概览(tab=searchParams 保持)
  - 任务行点击 → 跳 `/tasks/{task_id}`
  - 预览链接 → `window.open(preview_url, '_blank')`,当前页不动
  - 口径切换 → 仅统计区数字/高亮变化,无请求(R1 已一次性返回两口径数据)
- **错误处理行**:
  - summary 加载失败(网络/500)→ 概览容器内错误条「加载项目概览失败」+ 重试按钮(照 AuditLogsPage 先例),页头与其他 Tab 不受影响
  - 404(private 非成员)→ 沿用项目详情页既有 404 行为
  - 无写操作,无防重需求
