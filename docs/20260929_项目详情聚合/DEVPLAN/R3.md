- **实现要点**:
  1. tabs 数组改 4 项(key/label):overview=概览、requirements=需求、tasks=任务、manage=管理
  2. 默认值:`searchParams.get('tab') ?? 'overview'`;**兼容映射**(读侧归一,不改写 URL 或改写均可,实现取「归一到 manage 并设置初始子 Tab」):
     - `?tab=repos` → manage + settingsTab 初始 'repos' 对应仓库
     - `?tab=members` → manage + 初始成员
     - `?tab=settings` → manage + 初始设置(MCP)
     - 其余非法值 → overview
  3. 管理子 Tab state 沿用 `useState<'repos'|'members'|'settings'>`;初始值由兼容映射决定(直接进入 manage 时默认 'repos')
  4. ⋮ 菜单「设置」项 → `navigate(?tab=manage)`(子 Tab 落 settings);归档/删除项不动
  5. 需求/任务分支代码原样平移,不改组件
- **页面交互流程**:
  - Tab 切换:点 Tab → navigate(`?tab={key}`)→ 内容区切换(URL 可分享/刷新保持)
  - 管理子 Tab:点子 Tab → 组件内 state 切换(无 URL 变化,沿现状)
  - 旧书签:带 ?tab=settings 打开 → 落管理 Tab 设置子 Tab;?tab=repos → 落管理 Tab 仓库子 Tab
  - ⋮ 菜单:设置 → 管理 Tab;归档/删除 → 既有确认 Dialog 流程不动
