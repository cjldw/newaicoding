- **实现要点**:
  1. 端点放 backend/app/api/projects.py:`@router.get("/{project_id}/summary")`,三步鉴权后调 `project_service.build_project_summary(db, project)`,返回 success(data)
  2. `build_project_summary` 落 project_service.py:需求按状态计数(全需求)、任务按 (type,status) 分组计数**一次查询**然后内存拆四维(比四次查询省);polish_tasks=type=requirement 计数;active 口径按字段定义表
  3. tokens:一条 select(func.coalesce(sum(in),0), func.coalesce(sum(out),0)) 总量 + 按 type 分组 sum 各一条(或 group by type 一条拿 in/out 拆分),组装 by_type
  4. recent_7d:4 条 count 查询(需求 created/完成、任务 created/完成),时间阈值 now-7d(Python 侧计算后传参,不用 MySQL NOW(),保时区一致)
  5. latest_release:release 任务 created_at 倒序 limit 1,取 extended_attributes 的 deploy_host/deploy_port/deploy_phase,preview_url 按 `http://{slug}--{task_short}--{port}.{preview_base_domain}` 规则组装(route_service.get_preview_base_domain);deploy_phase≠deployed 时 preview_url 置空串
  6. recent_requirements/recent_tasks:各自 updated_at 倒序 limit 5,白名单字段响应
  7. 全部顺序 await;不加新索引;零迁移
