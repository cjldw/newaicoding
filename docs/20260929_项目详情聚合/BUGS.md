# BUGS.md — 项目详情页聚合改版

> 记录测试/走查发现的问题。状态:open → fixed → verified。

| 编号 | 状态 | 关联需求点 | 类型 | 描述 |
|---|---|---|---|---|
| BUG-001 | fixed | R3 | 功能缺失 | 项目详情页缺「测试」「发布」Tab:R3 收敛后项目内无法直达本项目的测试任务/发布任务列表(测试/发布任务混在「任务」Tab 全类型分组列表里)。用户要求补回,样式按「任务」Tab(ProjectTaskList 按需求分组列表)来 |

## BUG-001 详情

- **复现步骤**:打开任意项目详情页 → Tab 条只有 概览/需求/任务/管理 → 无「测试」「发布」入口
- **期望**:新增「测试」「发布」两个主 Tab,展示本项目 type=test / type=release 的任务列表,样式与「任务」Tab 一致(按需求分组、状态筛选、搜索、行点击跳任务详情)
- **决策(rd-fix 留痕)**:数据复用 `useProjectTaskList(projectId)` 客户端按 type 过滤——该接口一次返回项目全量任务,三 Tab 共享同一 queryKey 缓存零额外请求;不引入 dashboard 个人口径接口(范围外:不改 dashboard)
