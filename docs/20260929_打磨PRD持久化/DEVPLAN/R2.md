- **状态**:✅ 完成(代码+测试全绿;commit 待用户确认——遵循全局 git 规则不自动提交)
- **PRD 引用**(边界定义 + 验收标准 + 异常场景摘录,下游不读 PRD 全文):
  - **做什么**:两个回传时机——**主**:type=requirement 任务每轮对话结算后(send_message_stream 收尾),若容器在线 → 回读 `{prd_file_path}` → 非空则更新副本;**兜底**:预览请求时若库无副本且容器在线 → 回读并回填(覆盖用户在终端手动改文件的场景)
  - **不做什么**:不做 file_watcher 事件驱动;不阻断对话/预览主流程(回传失败对用户透明);拉取失败记日志跳过(不重试轰炸,下一时机自然重试)
  - **前置条件**:容器 running;`prd_file_path` 非空
  - **异常/边界场景**(PRD 原文):容器恰在结算瞬间销毁 → 拉取失败跳过,不报错给用户;用户终端手改文件 → 下一次预览兜底拉取覆盖副本;回读失败/超时 → 记日志跳过,对话与预览主流程不受影响
  - **验收标准**:①打磨首轮 AI 回复后 ≤5s,`prd_content` 非空且与容器内文件一致 ②人为杀容器后副本仍在(R1/R3 联合验收)③回读失败时对话正常出回复、预览正常降级,无 500
