- **接口契约**:
  ### 接口:PRD 副本读取(免容器预览)
  - 类型:**新建** `GET /api/requirements/{req_id}/prd-content`(路由文件 `backend/app/api/requirements.py`;注册顺序注意:不得早于 `/requirements/branch-preview` 之类静态前缀路由被路径参数吞掉的问题——本路径含 `{req_id}` 后接静态段 `prd-content`,FastAPI 按声明顺序匹配,放在 `/requirements/{req_id}` 之前声明以保险)
  - 鉴权:`get_current_user` + `get_project_or_404(req.project_id)` + `require_project_role(db, project, user, "viewer")`(与 `GET /requirements/{req_id}` 同模式)
  - 请求参数:无 query/body(路径参数 req_id 即 CHAR(36))
  - 响应结构:
    | 字段 | 类型 | 说明 |
    |---|---|---|
    | prd_content | string \| null | PRD.md 全文;null=无副本(前端据此空态) |
    | source | 'db' \| 'container' \| 'none' | 内容来源(调试/降级可见性) |
  - 降级链(服务端顺序):①`req.prd_content` truthy → 返回 (content, 'db') ②否则定位打磨任务(`requirement.polish_task_id`;空则取 req_id 关联 type=requirement 最新任务)→ 查 running 容器 + runner 在线 → 调 R2 同一同步函数回读回填 → 成功返回 (content, 'container') ③任何一步不满足/失败 → 返回 (null, 'none'),**HTTP 恒 200**(除 401/403/404),不抛 500
  - 错误码与异常:401 未登录 / 403 非项目成员 / 404 需求不存在(沿用现有 `get_requirement_or_404`);无业务错误码(降级全部收敛为 200+null)
  - 分页:无

- **实现要点**(页面生成逻辑):

- **页面交互流程**:
